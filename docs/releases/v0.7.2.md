# v0.7.2 — Local embeddings and vector search

## Mục tiêu

Bổ sung lớp vector embedding cục bộ cho các chunk tài liệu đã có cấu trúc ở v0.7.1, tạo nền cho hybrid retrieval ở các bản tiếp theo mà không phát sinh chi phí API embedding.

## Thay đổi chính

- Thêm `IKnowledgeEmbeddingService` để tách thuật toán embedding khỏi phần lưu trữ và truy xuất.
- Backend mặc định dùng `local-feature-hash-v1`, vector 384 chiều, chạy hoàn toàn trên máy.
- Vector local kết hợp word features, word bigrams và character n-grams sau khi chuẩn hóa Unicode và bỏ dấu.
- Thêm bảng `ChunkEmbeddings` trong SQLite để lưu vector theo từng chunk.
- Mỗi vector gắn `ModelId`, số chiều, SHA-256 của nội dung và thời điểm cập nhật.
- Khi model/vector schema thay đổi hoặc nội dung chunk thay đổi, index được tái tạo tự động.
- Các chunk từ dữ liệu cũ được backfill khi lần đầu dùng semantic search hoặc đọc trạng thái vector.
- Thêm API `GET /api/knowledge/semantic-search`.
- Thêm API `GET /api/knowledge/embeddings/status` để xem model, dimensions và tiến độ index.
- Kết quả semantic search trả `SimilarityScore` cùng page/heading/section metadata từ v0.7.1.
- UI Kho dữ liệu có thêm nút “Tìm ngữ nghĩa” và trạng thái chỉ mục vector.
- Xóa document sẽ cascade xóa vector tương ứng.

## Quyền riêng tư và chi phí

- v0.7.2 không gửi nội dung chunk tới dịch vụ embedding bên ngoài.
- Không cần API key riêng cho embedding.
- Không phát sinh chi phí embedding cloud.
- Vector và metadata được lưu tại `%LOCALAPPDATA%\PersonalAI\Knowledge` cùng kho dữ liệu local.

## Giới hạn chủ đích

`local-feature-hash-v1` là embedding dạng feature hashing deterministic, phù hợp làm nền vector local và tìm nội dung gần về từ/cụm từ. Đây chưa phải neural sentence embedding nên khả năng hiểu từ đồng nghĩa hoặc quan hệ ngữ nghĩa sâu còn hạn chế.

Các bản tiếp theo sẽ xây trên abstraction hiện tại để bổ sung hybrid retrieval, reranking và có thể thêm neural embedding provider mà không phải thay đổi hợp đồng lưu trữ vector.
