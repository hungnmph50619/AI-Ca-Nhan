# AI Cá Nhân v0.7.6 — RAG Production Hardening & Evaluation

## Mục tiêu

v0.7.6 bổ sung lớp kiểm tra chất lượng cho pipeline RAG local trước khi chuyển sang tool framework. Phiên bản này không thay đổi chiến lược hybrid retrieval v0.7.3; thay vào đó nó đo, phát hiện và phục hồi các lỗi index có thể xử lý an toàn.

## Chức năng mới

- `GET /api/knowledge/quality/status`
  - chạy SQLite `quick_check` và `foreign_key_check`;
  - kiểm tra tệp gốc local còn tồn tại;
  - so SHA-256 tệp gốc với metadata đã lưu;
  - phát hiện tài liệu không có chunk hoặc chunk index không liên tục;
  - kiểm tra coverage của embedding model hiện hành;
  - phát hiện nội dung trùng sau khi chuẩn hóa Unicode, chữ hoa/thường và whitespace.
- `POST /api/knowledge/quality/evaluate`
  - chạy benchmark deterministic trên hybrid search;
  - hỗ trợ tối đa 50 case/lần;
  - trả Hit@K, Mean Reciprocal Rank và content-match rate;
  - benchmark chạy local, không gọi LLM.
- `POST /api/knowledge/quality/repair`
  - tạo lại vector còn thiếu;
  - re-index tài liệu khi chunk/index state có thể phục hồi;
  - không tự sửa tệp gốc bị mất hoặc checksum bị lệch;
  - không chạy repair khi SQLite integrity check thất bại.
- UI Kho dữ liệu có bảng `Chất lượng RAG local`, nút kiểm tra và nút sửa chỉ mục an toàn.

## Nguyên tắc an toàn

- Tệp gốc có checksum lệch chỉ được báo lỗi; hệ thống không tự chấp nhận nội dung bị thay đổi ngoài ứng dụng.
- Database integrity lỗi sẽ chặn repair tự động.
- Duplicate-content ở v0.7.6 là cảnh báo để người dùng quyết định; hệ thống chưa tự xóa hoặc hợp nhất tài liệu.
- Evaluation chỉ đọc dữ liệu và chạy retrieval local.

## CI / regression

CI kiểm tra:

- build .NET 8;
- memory regression;
- upload PDF/DOCX/TXT/Markdown;
- document management, rename và re-index;
- structured metadata, semantic/hybrid retrieval và citation source;
- RAG quality status ở trạng thái khỏe;
- benchmark retrieval với expected file/content;
- phát hiện duplicate content chuẩn hóa;
- phát hiện checksum tệp gốc bị thay đổi và đảm bảo safe repair không ghi đè;
- metadata export, bulk delete;
- JavaScript syntax gồm `v076.js`.

## Phạm vi chưa làm

- Không tự xóa tài liệu trùng.
- Không OCR PDF ảnh.
- Không thay embedding local bằng API embedding.
- Không tự sửa database khi SQLite integrity check thất bại.
- Tool framework bắt đầu ở nhánh v0.8.x sau khi RAG core ổn định.
