# v0.8.0 — Tool Framework

## Mục tiêu

Đặt nền tảng an toàn để AI Cá Nhân có thể sử dụng công cụ trong các bản v0.8.x sau, nhưng không cho model tự ý thực thi hành động trong v0.8.0.

## Có gì mới

- Registry deterministic cho các công cụ được đăng ký trong ứng dụng.
- Mỗi công cụ có `name`, `description`, `version`, JSON input schema, permission bắt buộc, timeout và cờ local/external.
- Permission chuẩn hóa thành `READ`, `WRITE`, `DELETE`, `EXTERNAL`, `SENSITIVE`.
- `WRITE`, `DELETE`, `EXTERNAL`, `SENSITIVE` luôn yêu cầu xác nhận rõ ràng trước khi executor cho chạy.
- Input được validate trước khi gọi tool; arguments thừa có thể bị chặn bằng `additionalProperties: false`.
- Timeout do definition của tool quyết định, người gọi không được tự tăng timeout.
- Executor trả kết quả có cấu trúc với invocation id, trạng thái, thời gian chạy, permission yêu cầu/đã cấp và output/error.
- Lỗi nội bộ không trả stack trace hoặc exception detail ra client; chi tiết kỹ thuật chỉ ghi ở server log.
- API mới:
  - `GET /api/tools`
  - `GET /api/tools/{toolName}`
  - `POST /api/tools/execute`
- Hai reference tool local để kiểm chứng framework:
  - `local.text_stats`
  - `local.clock`
- UI sidebar có mục **Công cụ** để xem catalog, permission và timeout của các tool đã đăng ký.

## Boundary an toàn của v0.8.0

- Chat/model chưa tự chọn hoặc tự gọi tool.
- Không có HTTP tool, file write, delete, shell, browser hoặc external connector trong bản này.
- Không có cơ chế nào để tool tự đăng ký runtime từ input người dùng.
- Tool không thể tự cấp permission cho chính nó.
- Governance/permission policy vẫn nằm ngoài đường thực thi của tool.

## Kiểm thử CI

CI giữ toàn bộ regression Memory + RAG v0.7.6 và bổ sung:

- catalog và schema của tool;
- từ chối khi thiếu `READ`;
- từ chối input thiếu trường bắt buộc;
- thực thi `local.text_stats` khi có permission;
- thực thi `local.clock`;
- từ chối tool chưa đăng ký;
- JavaScript syntax cho `v080.js`.

## Bước tiếp theo

v0.8.1 sẽ bổ sung nhóm internal tools hữu ích như tìm memory, tìm documents, calculator/date theo cùng registry và permission pipeline này. Việc cho model tự chọn tool chỉ nên được bật khi luồng approval/audit đủ rõ ràng.
