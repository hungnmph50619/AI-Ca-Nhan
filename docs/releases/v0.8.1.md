# v0.8.1 — Internal Tools

## Mục tiêu

Mở rộng Tool Framework v0.8.0 bằng các công cụ nội bộ hữu ích nhưng vẫn giữ nguyên nguyên tắc local-first, deterministic và đi qua cùng permission/schema/timeout pipeline.

## Công cụ mới

- `memory.search`
  - Tìm trong trí nhớ cá nhân đang bật.
  - Bỏ qua trí nhớ hết hạn; mặc định bỏ qua stale memory.
  - Có `limit`, lọc `kind` và tùy chọn `includeStale`.
  - Xếp hạng từ khóa deterministic, không gọi model.

- `documents.search`
  - Dùng chính Hybrid Retrieval hiện có của Knowledge/RAG.
  - Kết hợp keyword + local vector + deterministic rerank.
  - Trả metadata chunk, file, trang/heading/section và score.

- `local.calculate`
  - Parser số học local, không dùng `eval`, shell hay code execution.
  - Hỗ trợ `+`, `-`, `*`, `/`, `%`, dấu ngoặc, unary sign và số thập phân.
  - Chia cho 0 hoặc biểu thức sai được trả về `invalid-input`.

- `local.date_math`
  - Cộng ngày/giờ/phút vào mốc ISO-8601.
  - Tính chênh lệch giữa hai mốc thời gian.
  - Không gọi dịch vụ thời gian bên ngoài.

- `app.summary`
  - Đọc thống kê tổng quan Memory, Knowledge và embedding index.
  - Không trả nội dung chi tiết của memory/chunk.

Hai utility từ v0.8.0 vẫn được giữ nguyên:

- `local.text_stats`
- `local.clock`

Tổng cộng registry v0.8.1 có 7 tool.

## Policy và an toàn

- Tất cả internal tool mới chỉ yêu cầu `READ`.
- Mỗi lần thực thi vẫn đi qua registry, JSON schema validation, permission policy và timeout cố định.
- `WRITE`, `DELETE`, `EXTERNAL`, `SENSITIVE` vẫn bắt buộc xác nhận rõ ràng theo Tool Framework.
- Semantic validation bên trong tool có thể trả `invalid-input` thay vì biến lỗi người dùng thành lỗi máy chủ.
- Calculator không dùng dynamic evaluation.
- Không có shell, file write/delete, HTTP, browser hay connector tool trong bản này.
- Chat/model vẫn chưa tự chọn hay tự gọi tool trong v0.8.1.

## API

Giữ nguyên API Tool Framework:

- `GET /api/tools`
- `GET /api/tools/{toolName}`
- `POST /api/tools/execute`

`frameworkVersion` và app version được nâng lên `0.8.1`.
