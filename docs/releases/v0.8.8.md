# PersonalAI v0.8.8 — Native Tool Result Round-trip

## Mục tiêu

v0.8.8 hoàn tất vòng function calling một bước: sau khi provider tạo native function proposal, người dùng cho phép tool chạy và PersonalAI có kết quả, ứng dụng có thể gửi đúng kết quả đó trở lại **cùng provider/model đã tạo function call** để model viết câu trả lời cuối.

Điểm quan trọng: đây vẫn không phải agent loop. Model không được tự chạy tool và lượt continuation không được cấp thêm tool.

## Luồng mới

1. Người dùng bật **Đề xuất công cụ**.
2. OpenAI/Gemini tạo native function proposal như v0.8.7.
3. Server validate tool + arguments và tạo proposal.
4. Người dùng bấm chạy; WRITE/DELETE vẫn cần confirmation riêng.
5. Tool chạy local và tạo `localSummary`.
6. Nếu proposal đến từ native function calling, execution response có `canNativeContinue=true`.
7. UI hiển thị nút **Hoàn tất câu trả lời bằng AI**.
8. Trước khi gửi tool result ra ngoài, người dùng phải xác nhận riêng.
9. Server lấy native context đã lưu theo invocation, không nhận lại function name, arguments hay output từ client.
10. Tool result được gửi về đúng provider/model của proposal.
11. Provider trả câu trả lời cuối. Không có tool nào được cấp trong lượt continuation.

## API

### Execution response

`POST /api/tools/orchestrate/execute` trả thêm:

- `canNativeContinue`;
- `nativeContinueExpiresAt`.

Manual proposal qua `/api/tools/orchestrate/prepare` không có native context nên `canNativeContinue=false`.

### Native continuation

`POST /api/tools/orchestrate/continue-native`

Input:

```json
{
  "invocationId": "...",
  "confirmedExternal": true
}
```

Client chỉ gửi invocation ID và trạng thái xác nhận. Tool result thật được lấy từ completed invocation phía server.

Nếu chưa xác nhận gửi dữ liệu ra provider, endpoint trả 403. Invocation không tồn tại/hết hạn trả 404. Invocation manual không có native context trả 400.

## OpenAI Responses API

PersonalAI giữ `store=false` và continuation theo hướng stateless:

- yêu cầu `reasoning.encrypted_content` ở lượt planning để các reasoning context item cần thiết có thể được replay khi `store=false`;
- lưu output items của response planning trong RAM;
- khi tool chạy xong, gửi lại hội thoại giới hạn + toàn bộ output items cần thiết của lượt function call;
- thêm `function_call_output` với đúng `call_id`;
- không gửi `tools` trong request continuation;
- thêm continuation instructions để tool result được coi là dữ liệu không đáng tin cậy.

Việc giữ toàn bộ output items giúp bảo toàn function-call item và các context item cần thiết của Responses API, thay vì chỉ dựng lại name/arguments.

## Gemini Generate Content

PersonalAI giữ chính xác model content chứa `functionCall` của lượt planning và gửi lại nó trước `functionResponse`.

- `functionResponse.name` khớp function call;
- nếu Gemini trả `functionCall.id`, ID đó được giữ và gửi lại;
- function declaration vẫn được gửi để giữ ngữ nghĩa của function;
- `functionCallingConfig.mode = "NONE"` trong continuation nên model không được gọi thêm function;
- model/provider được cố định theo native context ban đầu.

## Privacy và safety

- Tool result không tự động rời máy.
- Native continuation cần `confirmedExternal=true` riêng.
- Kết quả của tool có permission `SENSITIVE` không đủ điều kiện native continuation.
- Output gửi provider bị giới hạn 16.000 ký tự.
- Payload đánh dấu rõ `outputTruncated` và kèm `localSummary`.
- Tool output được coi là untrusted data trong continuation instructions.
- Câu trả lời continuation bị giới hạn 8.000 ký tự trước khi lưu vào hội thoại local.
- Native context/completed invocation chỉ giữ tạm trong RAM khoảng 10 phút, tối đa 100 mục.
- Response continuation được cache theo invocation để tránh gửi cùng tool result nhiều lần.
- Nếu người dùng đổi active provider sau khi proposal được tạo, continuation vẫn dùng provider/model ban đầu; API key hiện tại của provider đó vẫn phải còn hợp lệ.

## Giao diện tiếng Việt

Toàn bộ nội dung hướng tới người dùng trong luồng công cụ được ưu tiên hiển thị bằng tiếng Việt:

- tên công cụ có nhãn tiếng Việt thay cho mã kỹ thuật;
- quyền hiển thị là ĐỌC, GHI, XÓA, BÊN NGOÀI và NHẠY CẢM;
- các nhãn như nguồn đề xuất, tham số, kết quả, nhà cung cấp, mô hình và trạng thái thực thi đều dùng tiếng Việt;
- các thuật ngữ kỹ thuật trong kho dữ liệu như vector, hybrid, rerank, metadata, chunk, checksum và re-index được thay bằng cách diễn đạt tiếng Việt dễ đọc;
- tên sản phẩm, định dạng và chuẩn kỹ thuật như OpenAI, Gemini, PDF, DOCX, JSON, UTF-8, SHA-256 vẫn giữ nguyên khi cần để tránh làm sai nghĩa.

## UI

Tool result card ưu tiên native flow nếu có context:

- hiển thị local summary trước;
- cho xem output preview;
- nút **Hoàn tất câu trả lời bằng AI**;
- confirmation giải thích output sẽ được gửi về provider/model ban đầu;
- sau khi hoàn tất, trạng thái privacy được cập nhật.

Manual proposal hoặc execution không có native context vẫn dùng nút **Diễn giải bằng AI** của v0.8.6 nếu đủ điều kiện.

## Kiểm thử

CI bao phủ:

- version/framework 0.8.8;
- toàn bộ Memory/RAG/tool/orchestration regression;
- manual proposal không được đánh dấu native-continuable;

- invocation không tồn tại trả 404;
- static contract cho `function_call_output` của OpenAI;
- static contract cho Gemini `functionResponse` + `mode="NONE"`;
- provider resolver theo provider gốc;
- native context retention và giới hạn output;
- UI JavaScript syntax.

## Ngoài phạm vi

v0.8.8 chưa tự động chạy READ tool, chưa tự động bấm native continuation, chưa cho model gọi tool lần hai từ kết quả tool thứ nhất và chưa có autonomous multi-step agent loop.
