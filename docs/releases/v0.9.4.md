# PersonalAI v0.9.4 — Workspace

## Mục tiêu

v0.9.4 đưa **Workspace** thành ranh giới dữ liệu thực sự của PersonalAI. Người dùng có thể chuyển giữa Cá nhân, Công việc, Học tập, AI Cá Nhân và Du lịch; mỗi không gian giữ dữ liệu và lịch sử riêng thay vì trộn chung.

Theo roadmap, workspace gồm Memory, Documents, Tasks, Files, Conversations và dành trước Agents/Policies.

## Workspace Foundation

Có sẵn 5 workspace:

- `personal` — Cá nhân
- `work` — Công việc
- `study` — Học tập
- `ai-ca-nhan` — AI Cá Nhân
- `travel` — Du lịch

Có thể tạo workspace tùy chỉnh, tối đa 20 workspace.

API:

- `GET /api/workspaces`
- `GET /api/workspaces/{workspaceId}`
- `POST /api/workspaces`
- `PATCH /api/workspaces/{workspaceId}`

Workspace hiện tại được truyền qua header `X-PersonalAI-Workspace`. ID không tồn tại bị từ chối bằng HTTP 400.

## Phân tách dữ liệu

### Memory

Memory có `WorkspaceId`. Đọc, tạo, sửa, bật/tắt, xóa, import và thống kê chỉ thao tác trên workspace hiện tại. Memory cũ không có workspace được coi là `personal`.

### Documents / RAG

Mỗi workspace có knowledge database và thư mục file riêng.

- `personal` tiếp tục dùng vị trí dữ liệu cũ để giữ tương thích.
- workspace khác dùng `PersonalAI/Workspaces/data/{workspaceId}/Knowledge`.

Document search, embeddings, hybrid search, source reader, quality và document management đều dùng storage của workspace hiện tại.

### Tasks

Task có `WorkspaceId`; SQLite có cột `workspace_id`.

- danh sách task chỉ trả task của workspace hiện tại;
- get/execute/retry/resume/cancel không đi xuyên workspace;
- giới hạn 50 task áp dụng theo workspace;
- task cũ được migrate về `personal`.

Task Dependencies v0.9.3 vẫn được giữ nguyên trong workspace.

### Files

Các tool `workspace.*` có sandbox theo workspace. `personal` giữ root cũ; workspace khác dùng root riêng nên không nhìn thấy file của nhau.

### Conversations

Conversation tiếp tục lưu trong browser nhưng key được namespace:

`personal-ai-v0.9.4-workspace-{workspaceId}`

Đổi workspace sẽ reload và tải lịch sử của workspace mới. Lịch sử cũ chỉ migrate vào `personal`.

## UI

Sidebar có workspace switcher và màn hình quản lý:

- chuyển workspace;
- xem workspace hiện tại;
- tạo workspace tùy chỉnh;
- đổi tên/mô tả;
- xem module hoạt động.

v0.9.4 chưa cho xóa workspace để tránh dữ liệu mồ côi.

## Module contract

Hoạt động: `memory`, `documents`, `tasks`, `files`, `conversations`.

Dành trước: `agents`, `policies`.

Hai module dành trước chỉ là contract kiến trúc, chưa phải autonomous agent hay policy engine.

## An toàn và tương thích

- Không tăng quyền tự động.
- WRITE/DELETE vẫn cần xác nhận.
- Không scheduler nền.
- Không parallel task execution.
- Không agent loop tự trị.
- Dữ liệu cũ fallback về workspace `personal`.
- Workspace header được validate ở server.

## Kiểm thử

CI kiểm tra built-in workspaces, workspace tùy chỉnh, invalid workspace, isolation của Memory/Documents/Tasks/Files, version contract, build .NET và syntax JavaScript.

## Bước tiếp theo

Theo roadmap, **v0.9.5 — Context Manager** sẽ quyết định Memory, Documents và Tasks nào trong workspace thực sự cần đi vào context của từng yêu cầu.
