# PersonalAI v0.9.6 — Audit Foundation

## Mục tiêu

v0.9.6 triển khai **Audit Foundation** theo roadmap.

Mỗi hành động quan trọng được ghi bằng một schema chung:

- Time
- Agent
- Action
- Tool
- Target
- Reason
- Result

Audit v0.9.6 là lớp nhật ký vận hành cấp hệ thống, rộng hơn Tool Activity Log của v0.8.9.

## Audit schema

Mỗi event gồm:

```
AuditId
Time
WorkspaceId
Agent
Action
Tool
Target
Reason
Result
```

Agent hiện có:

- `user`
- `personal-ai`
- `task-engine`
- `system`

Ví dụ:

```
Time:   2026-09-18T...
Agent:  task-engine
Action: task.step.execute
Tool:   workspace.create_directory
Target: task:<id>
Reason: user-confirmed-step
Result: succeeded
```

## Phạm vi được audit

### Workspace

Ghi:

- `workspace.create`
- `workspace.update`

Workspace mới nhận event tạo workspace trong chính audit scope của nó.

### Memory

Ghi:

- `memory.create`
- `memory.update`
- `memory.enable`
- `memory.disable`
- `memory.delete`
- `memory.delete-all`
- `memory.import`

Audit không lưu nguyên văn nội dung Memory.

### Documents / RAG

Ghi:

- `document.upload`
- `document.rename`
- `document.reindex`
- `document.delete`
- `document.bulk-delete`

Audit chỉ lưu ID/target và metadata hành động, không lưu nội dung tài liệu.

### Tasks

Ghi:

- `task.prepare`
- `task.plan`
- `task.step.execute`
- `task.retry.prepare`
- `task.resume`
- `task.cancel`

Task Engine được nhận diện riêng bằng agent `task-engine`.

Nếu một bước tool bị yêu cầu xác nhận hoặc retry bị policy chặn, event audit ghi `denied`.

### Tools

Ghi:

- `tool.proposal.prepare`
- `tool.proposed`
- `tool.execute`
- `tool.synthesize`
- `tool.native-continue`

Tool name được lưu nhưng arguments/output đầy đủ không được copy sang unified audit.

Tool Activity Log cũ vẫn giữ nguyên trong v0.9.6 để tương thích và để tiếp tục lưu SHA-256 của arguments/output.

### Context / Chat

Ghi:

- `context.preview`
- `chat.completed`
- AI tool proposal trong chat

Không lưu prompt hoặc câu trả lời AI vào audit.

## Storage

Audit được lưu local bằng SQLite:

```
%LOCALAPPDATA%\PersonalAI\Audit\audit.db
```

Có thể override root bằng cấu hình:

```
Audit:Root
```

Giới hạn:

- retention: 90 ngày
- tối đa: 10.000 event
- query tối đa: 200 event/lần

Database dùng WAL và busy timeout giống các store SQLite khác.

## Workspace isolation

Audit API mặc định luôn scoped theo workspace hiện tại thông qua:

```
X-PersonalAI-Workspace
```

Không có endpoint để một workspace đọc audit của workspace khác.

## API

### Danh sách event

```
GET /api/audit
```

Filter tùy chọn:

- `limit`
- `agent`
- `action`
- `result`

### Tổng hợp

```
GET /api/audit/summary
```

Trả:

- tổng event;
- số event theo agent;
- số event theo result;
- số event theo action.

## Append-only qua API

v0.9.6 không cung cấp:

- POST audit thủ công;
- PUT/PATCH audit;
- DELETE audit.

Người dùng có thể xem nhưng không thể chỉnh sửa/xóa event qua UI hoặc API.

Đây là **append-only application contract**, chưa phải tamper-proof cryptographic ledger.

## UI

Sidebar có mục **Nhật ký**.

Màn hình hiển thị đúng các trường:

```
Thời gian
Tác nhân
Hành động
Công cụ
Đối tượng
Lý do
Kết quả
```

Có filter theo agent và result.

UI không hiển thị nội dung Memory, prompt, nội dung tài liệu hoặc full tool arguments.

## Privacy

Unified audit cố tình chỉ lưu metadata có giới hạn.

Không lưu:

- prompt;
- response AI;
- Memory content;
- document content;
- tool arguments đầy đủ;
- tool output đầy đủ;
- API key.

Reason sử dụng các mã/lý do vận hành cố định như `user-request`, `chat-tool-selection`, `safe-retry` thay vì copy nội dung người dùng.

## Tương thích

- Tool Activity Log v0.8.9 vẫn hoạt động.
- Task persistence v0.9.1 không đổi.
- Task dependency v0.9.3 không đổi.
- Workspace isolation v0.9.4 không đổi.
- Context Manager v0.9.5 không đổi.
- Audit failure được log warning nhưng không làm hỏng hành động chính của người dùng.

## Bước tiếp theo

Theo roadmap, **v0.9.7 — Undo Foundation** sẽ lưu đủ state trước hành động cho những thao tác có thể đảo ngược, để một số action có thể rollback có kiểm soát.

Audit v0.9.6 là nền cần thiết để v0.9.7 biết hành động nào đã xảy ra, ai/agent nào thực hiện, mục tiêu nào bị thay đổi và kết quả ra sao.
