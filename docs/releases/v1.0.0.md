# PersonalAI v1.0.0 — Stable Personal AI Core

## Mục tiêu

v1.0.0 đánh dấu mốc **Stable Personal AI Core**.

Bản này không mở thêm quyền tự động mới. Thay vào đó, nó ổn định các nền tảng đã xây dựng từ v0.6 đến v0.9:

- Memory
- Documents / RAG
- Tasks
- Files
- Workspace
- Context Manager
- Tool Framework
- Audit
- Undo
- Conversations

Mục tiêu là tạo một contract đủ rõ và đủ kiểm thử để các giai đoạn sau như Browser, Computer Use hoặc Connectors không phải dựa trên một core mơ hồ.

## Release contract tập trung

Version không còn được hard-code độc lập ở từng endpoint backend.

Contract lõi:

- Version: `1.0.0`
- API contract: `1`
- Channel: `stable`

Backend dùng `PersonalAiRelease` làm nguồn version chính.

`/api/status` tiếp tục giữ các field cũ và bổ sung:

- `apiContractVersion`
- `channel`

Tool Framework dùng cùng release version.

## Stable capability contract

Endpoint mới:

`GET /api/system/capabilities`

Trả contract máy đọc được về:

- stable modules;
- reserved modules;
- safety guardrails;
- giới hạn cốt lõi;
- workspace header;
- request ID header.

Stable modules:

- workspace
- memory
- documents
- rag
- tasks
- files
- context
- tools
- audit
- undo
- conversations

Reserved cho giai đoạn sau:

- agents
- policies
- browser
- computer-use
- connectors

Việc một module nằm trong `reservedModules` không có nghĩa module đó đã được kích hoạt.

## Safety contract v1

Capability contract xác nhận các guardrail hiện tại:

- workspace isolation bật;
- WRITE cần confirmation;
- DELETE cần confirmation;
- EXTERNAL cần confirmation;
- Undo cần confirmation;
- không automatic multi-step execution;
- không background scheduler;
- không autonomous agent loop;
- không parallel tool calls.

v1.0.0 không nới bất kỳ guardrail nào của v0.9.7.

## Core readiness

Endpoint mới:

`GET /api/system/health`

Health check chỉ kiểm tra local core và **không gọi Gemini/OpenAI**.

Các module được kiểm tra trực tiếp:

- workspace;
- memory;
- documents;
- tasks;
- files sandbox;
- tool registry;
- audit;
- undo;
- AI provider configuration.

Readiness của local core không phụ thuộc vào việc API key đã được cấu hình hay chưa.

Nếu các module local hoạt động nhưng AI provider chưa cấu hình:

- `ready = true`
- `status = degraded`
- module `ai-provider` có trạng thái `unconfigured`

Nếu một local core module không đọc được:

- `ready = false`
- endpoint trả HTTP 503.

Exception kỹ thuật không được trả nguyên văn trong health response; chi tiết chỉ được ghi server log.

## API request hardening

Mọi response có request ID do server tạo:

`X-PersonalAI-Request-Id`

Các API response còn có:

`X-PersonalAI-Api-Version: 1`

API response được đặt `no-store` và có:

- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: no-referrer`

Unhandled exception trong `/api` được chuyển thành lỗi JSON đã sanitize:

```json
{
  "error": "Đã xảy ra lỗi nội bộ. Hãy thử lại.",
  "requestId": "..."
}
```

Stack trace, đường dẫn local và exception nội bộ không được gửi về client.

Request ID tương ứng vẫn được ghi server log để chẩn đoán.

## Core limits contract

v1.0.0 công bố các giới hạn nền hiện tại qua capabilities:

- tối đa 20 workspace;
- tối đa 50 task trên mỗi workspace;
- Context Manager tối đa 7.600 ký tự dữ liệu được chọn;
- workspace file tối đa 512 KB;
- Audit giữ 90 ngày, tối đa 10.000 event;
- Undo khả dụng 7 ngày, tối đa 500 record;
- Undo snapshot tối đa 512 KB.

Các giá trị được lấy từ cùng constant backend đang thực thi thay vì lặp lại bằng số độc lập trong endpoint.

## Regression và compatibility

v1.0.0 giữ các API và guardrail đã có từ v0.9.7.

Các regression quan trọng tiếp tục được kiểm tra:

- workspace isolation;
- Memory isolation;
- Documents/RAG isolation;
- Task persistence và interrupted recovery;
- Context Manager budget;
- Tool permission + confirmation;
- Audit persistence;
- Undo guard + persistence;
- JavaScript syntax;
- Vietnamese UI safety guardrails.

CI v1.0 bổ sung kiểm tra:

- release contract;
- capability contract;
- local health readiness;
- API contract header;
- server-generated request ID;
- workspace-scoped health;
- stable/reserved module contract;
- no autonomous/scheduler/parallel-tool regression.

## Không nằm trong v1.0.0

Stable Core không đồng nghĩa với autonomous agent.

v1.0.0 chưa thêm:

- browser automation;
- computer control;
- background task scheduler;
- autonomous agent loop;
- parallel tool execution;
- automatic confirmation;
- cloud multi-user auth;
- connectors tới Gmail, Calendar hoặc dịch vụ bên ngoài.

Các capability trên phải được phát triển ở giai đoạn sau với permission model riêng.

## Bước tiếp theo

Sau Stable Personal AI Core, roadmap có thể bắt đầu giai đoạn **v1.x — Controlled Capabilities**.

Thứ tự nên tiếp tục từ quyền thấp đến quyền cao, ví dụ:

1. read-only connectors;
2. browser observation/navigation có consent;
3. external actions có explicit confirmation;
4. computer-use sandbox;
5. policy engine;
6. agent orchestration với giới hạn vòng lặp và ngân sách rõ ràng.

Không nên mở autonomous execution trước khi permission, audit, undo và policy contract của capability tương ứng hoàn thiện.
