# PersonalAI v1.2.0 — Controlled Browser Agent

## Mục tiêu

v1.2.0 mở capability web đầu tiên phía trên Stable Core: **Browser Agent có kiểm soát**.

Bản này không dùng desktop click để giả lập browser và chưa đưa Chromium/JavaScript renderer vào core. Thay vào đó, nó xây một lớp browser-specific riêng để PersonalAI có thể:

- mở URL công khai bằng HTTP GET;
- theo redirect có kiểm tra;
- đọc text/title của trang;
- liệt kê liên kết;
- mở liên kết theo index;
- giữ snapshot trang hiện tại theo workspace.

Mọi browser tool đi qua Tool Framework, permission, confirmation, Tool Activity và Audit.

## Release contract

- Version: `1.2.0`
- API contract: `1`
- Channel: `controlled`

`controlledModules` gồm:

- `computer-use`
- `browser-agent`

`browser` không còn nằm trong reserved modules.

## Permission mới

Tool Framework thêm:

`BROWSER`

Quyền BROWSER luôn cần explicit confirmation.

Các permission hiện tại:

- READ
- WRITE
- DELETE
- EXTERNAL
- SENSITIVE
- COMPUTER
- BROWSER

Navigation còn cần EXTERNAL vì nó tạo request ra mạng.

## Browser engine v1.2

Engine:

`http-html`

Đây là engine HTTP/HTML có guard, không phải full browser renderer.

Có:

- HTTP/HTTPS GET;
- HTML/text/JSON reading;
- title extraction;
- visible-text normalization;
- link extraction;
- relative URL resolution;
- workspace-scoped in-memory session;
- maximum 20 URL trong history nội bộ.

Không có:

- JavaScript execution;
- cookies;
- localStorage;
- login session;
- form submit;
- POST/PUT/PATCH/DELETE;
- file upload;
- file download;
- browser extension;
- Chromium automation.

## Browser status API

`GET /api/browser/status`

Trả:

- version;

- response/text/link/redirect limits;
- known limitations.

Endpoint không tạo external request.

## Browser tools

### browser.session.info

Permissions:

- READ
- BROWSER

Đọc metadata của snapshot hiện tại:

- workspace;
- URL;
- origin;
- title;
- status code;
- content type;
- retrieval time;
- text/link count;
- navigation count.

Không tạo network request.

### browser.navigate

Permissions:

- READ
- EXTERNAL
- BROWSER

Luôn cần confirmation.

Chỉ dùng GET.

### browser.page.observe

Permissions:

- READ
- BROWSER

Luôn cần confirmation.

Đọc text + links đã nằm trong snapshot hiện tại, không tạo request mới.

Có thể giới hạn:

- maximumCharacters, tối đa 24.000;
- maximumLinks, tối đa 100.

### browser.link.open

Permissions:

- READ
- EXTERNAL
- BROWSER

Luôn cần confirmation.

Mở link bằng index từ snapshot hiện tại và áp dụng lại toàn bộ URL/DNS guard.

## SSRF và URL guard

Browser Agent chỉ cho:

- scheme `http` hoặc `https`;
- port 80 cho HTTP;
- port 443 cho HTTPS;
- hostname phân giải hoàn toàn tới public IP.

Bị chặn:

- localhost;
- `.localhost`;
- `.local`;
- `.internal`;
- `.home.arpa`;
- URL chứa user/password;
- loopback;
- RFC1918/private ranges;
- carrier-grade NAT;
- link-local;
- multicast;
- reserved/documentation ranges;
- IPv6 unique-local;
- IPv6 link-local;
- IPv6 documentation range.

DNS được kiểm tra trước request và được kiểm tra lại trong `ConnectCallback` tại thời điểm mở TCP connection. Nếu hostname có cả public và private/reserved address, request bị từ chối.

Redirect không được tự theo bởi HttpClient. Browser Agent tự xử lý tối đa 5 redirect và kiểm tra lại URL + DNS ở mỗi hop.

## Response guard

Giới hạn:

- response body: 1 MB;
- extracted page text: lưu nội bộ theo response nhưng tool observe tối đa 24.000 ký tự mỗi lần;
- links: tối đa 100;
- redirect: tối đa 5;
- URL: tối đa 2.048 ký tự;
- timeout request: 20 giây.

Chỉ nhận:

- `text/html`
- `text/plain`
- `application/xhtml+xml`
- `application/json`

`Content-Disposition: attachment` bị từ chối.

Binary content không được tải vào browser session.

## Workspace isolation

Browser session được key theo `WorkspaceId`.

Workspace A không đọc snapshot Browser Agent của Workspace B.

Session hiện được giữ trong RAM:

- restart app sẽ xóa browser session;
- không persist cookies hoặc page bodies xuống disk.

## Privacy và AI synthesis

Browser page output không tự bypass Tool Framework.

Navigation/observation phải được người dùng xác nhận trước.

Nếu kết quả tool được gửi tới provider AI để synthesis/native continuation, flow external-confirmation hiện có vẫn áp dụng.

Browser Agent không lưu credential, cookie hoặc authenticated browser session trong v1.2.0.

## Task Engine

Task Planner có thể nhìn thấy browser tools.

Điều này không làm browser tự chạy.

Mỗi browser step:

- phải được người dùng chủ động execute;
- phải qua BROWSER permission;
- navigation còn qua EXTERNAL;
- confirmation vẫn bắt buộc.

Safe Retry chặn browser step khỏi retry preparation vì network/page state có thể đã thay đổi.

## Health và capabilities

`/api/system/health` có module:

`browser-agent`

Vì browser engine v1.2 là managed HTTP/HTML và không phụ thuộc Chromium, nó có thể healthy trên Windows/Linux/macOS nếu app có network stack bình thường.

Browser Agent là controlled module, không phải dependency của Stable Core readiness.

Capability contract thêm:

- `browserUseRequiresConfirmation = true`
- `browserPrivateNetworkAccess = false`
- `browserSideEffectsEnabled = false`

Limits contract thêm browser response/text/link/redirect limits.
