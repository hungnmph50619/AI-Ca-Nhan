# PersonalAI v1.3.0 — Connector Foundation

## Mục tiêu

v1.3.0 mở lớp **Connectors** đầu tiên phía trên Stable Core.

Connector Foundation không dùng Browser Agent để lách authentication. Credential được cấu hình trực tiếp bởi người dùng, mã hóa local, tách theo workspace và chỉ được dùng bởi connector service.

Scope v1.3.0 là **authenticated read-only HTTPS connector**. Write actions được giữ tắt cho tới khi từng provider/action có permission và confirmation riêng.

## Release contract

- Version: `1.3.0`
- API contract: `1`
- Channel: `controlled`

`controlledModules` gồm:

- `computer-use`
- `browser-agent`
- `connectors`

`connectors` không còn nằm trong reserved modules.

## Permission mới

Tool Framework thêm:

`CONNECTOR`

CONNECTOR luôn cần explicit confirmation.

Permission contract hiện tại:

- READ
- WRITE
- DELETE
- EXTERNAL
- SENSITIVE
- COMPUTER
- BROWSER
- CONNECTOR

Connector response được coi là private/sensitive account data, nên authenticated read tool còn dùng `SENSITIVE`.

## Connector kind v1.3

Kind duy nhất trong v1.3.0:

`http-bearer`

Connection gồm public metadata:

- connector ID;
- workspace ID;
- name;
- kind;
- HTTPS base origin;
- enabled state;
- hasCredential;
- created/updated timestamps.

Bearer token không bao giờ được trả lại qua API.

## Credential storage

Connector credential được bảo vệ bằng ASP.NET Core Data Protection:

`PersonalAI.Connectors.v1`

Storage mặc định:

`%LOCALAPPDATA%\PersonalAI\Connectors\connections.json`

Có thể override bằng:

`Connectors:Root`

hoặc environment-style configuration:

`Connectors__Root`

File chỉ chứa ciphertext của Bearer token.

API list/status, Tool Activity Log và Audit không trả hoặc lưu plaintext token.

## Workspace isolation

Connector được gắn `WorkspaceId`.

Một workspace:

- chỉ nhìn thấy connection của chính nó;
- không dùng connector ID của workspace khác;
- không nhận credential từ workspace khác.

Giới hạn:

- tối đa 20 connector / workspace.

## Configuration API

### Status

```http
GET /api/connectors/status
```

Trả:

- kind được hỗ trợ;
- capability;
- limits;
- encryption state;
- write-action state;
- limitations.

### List

```http
GET /api/connectors
```

Chỉ trả public metadata.

### Create

```http
POST /api/connectors
Content-Type: application/json

{
  "name": "Example API",
  "kind": "http-bearer",
  "baseUrl": "https://api.example.com/",
  "bearerToken": "...",
  "confirmed": true
}
```

Không có `confirmed: true` trả 403.

### Delete

```http
DELETE /api/connectors/{connectorId}?confirmed=true
```

Xóa cả encrypted credential khỏi connector store.

Configuration create/delete được ghi Audit, nhưng token không được ghi.

## Connector tools

### connectors.list

Permissions:

- READ
- SENSITIVE
- CONNECTOR

Luôn cần confirmation.

Tool trả metadata connector trong workspace hiện tại, không trả credential.

### connector.http.get

Permissions:

- READ
- EXTERNAL
- SENSITIVE
- CONNECTOR

Luôn cần confirmation.

Arguments:

```json
{
  "connectorId": "...",
  "path": "/v1/me"
}
```

Tool lấy Bearer token ở backend sau khi permission/confirmation đã qua.

Token không nằm trong tool arguments.

## Network boundary

Base URL phải là:

- HTTPS;
- port 443;
- origin-only dạng `https://host/`;
- không có user info;
- không có path/query/fragment;
- public hostname/IP.

Tool path:

- phải bắt đầu bằng một dấu `/`;
- không được đổi origin;
- tối đa 1.024 ký tự.

Connector kiểm tra DNS trước request và kiểm tra lại tại TCP `ConnectCallback`.

Private/reserved hostname/IP bị chặn.

## Redirect safety

HttpClient:

`AllowAutoRedirect = false`

Connector tự xử lý redirect tối đa 3 lần.

Bearer token chỉ được gửi tiếp nếu redirect vẫn **cùng origin**.

Cross-origin redirect bị chặn thay vì forward Authorization header.

## Response boundary

v1.3.0 chỉ đọc:

- `application/json`;
- `application/*+json`;
- `text/plain`.

Không đọc binary/download.

Limits:

- response body tối đa 512 KB;
- text trả ra tool tối đa 32.000 ký tự;
- redirect tối đa 3;
- timeout 20 giây.

`Content-Disposition: attachment` bị từ chối.

## Write actions

`connectorWriteActionsEnabled = false`

v1.3.0 không có:

- POST;
- PUT;
- PATCH;
- DELETE qua connector tool;
- webhook send;
- email send;
- calendar create/update;
- file upload;
- purchase/payment;
- arbitrary headers;
- arbitrary auth schemes.

Không có generic “request any method” tool.

## Audit

Configuration ghi:

- `connector.create`
- `connector.delete`

Read execution tiếp tục được ghi qua Tool Framework / Tool Activity / Audit flow hiện có.

Audit target dùng connector/tool metadata, không dùng plaintext credential.

## Task Engine

Task Planner có thể nhìn thấy connector tools.

Task vẫn không tự chạy.

Safe Retry chặn bước có CONNECTOR permission khỏi retry preparation, vì external account state có thể đã thay đổi.

## Health và capabilities

`/api/system/health` có module:

`connectors`

Health check chỉ đọc connector store; nó không gọi API bên ngoài và không kiểm tra token bằng network request.

Connector là controlled capability nên không quyết định Stable Core readiness.

Safety contract thêm:

- `connectorUseRequiresConfirmation = true`
- `connectorSecretsEncrypted = true`
- `connectorWriteActionsEnabled = false`

Limits contract thêm connector count/response/text/redirect limits.

## UI

Sidebar có mục:

`Kết nối`

Panel cho phép:

- xem connector của workspace hiện tại;
- nhập name/base URL/Bearer token;
- lưu credential;
- xóa connector.

Bearer token là input một chiều:

- không hiển thị lại sau khi lưu;
- không có API “reveal token”.

Panel không chạy authenticated GET trực tiếp.

External connector reads vẫn phải qua Tool Framework.

## Gmail / Calendar / provider-specific OAuth

v1.3.0 **chưa giả vờ hỗ trợ Gmail/Calendar** bằng cách nhét cookie/token vào Browser Agent.

Google/Microsoft/GitHub provider-specific OAuth cần:

- provider manifest;
- OAuth redirect/device flow phù hợp;
- scopes tối thiểu;
- token refresh;
- revocation;
- action-specific permission;
- confirmation cho write actions.

Connector Foundation v1.3 tạo storage/permission/audit/network boundary để các provider đó được thêm đúng cách ở các mốc sau.
