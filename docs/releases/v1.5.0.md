# PersonalAI v1.5.0 — Android Companion

## Mục tiêu

v1.5.0 thêm **Android Companion** theo roadmap gốc.

Mục tiêu của mốc này là đưa PersonalAI lên điện thoại theo mô hình companion an toàn, không biến Android thành một remote-control client toàn quyền.

Android Companion v1.5.0 hỗ trợ:

- ghép nối thiết bị bằng one-time pairing code;
- device token riêng cho từng thiết bị;
- token scope theo workspace;
- trạng thái core/AI provider;
- chat với Memory/RAG/Task Context;
- xem danh sách Tasks ở chế độ read-only;
- revoke device từ desktop;
- Android app thật trong repository.

Không có remote tool execution, task mutation, file mutation hay autonomous background agent.

## Pairing model

Desktop tạo pairing code qua:

```http
POST /api/companion/admin/pairing/start
```

Body:

```json
{
  "confirmed": true
}
```

Pairing code:

- dài 12 ký tự;
- loại bỏ ký tự dễ nhầm;
- sống tối đa 5 phút;
- one-time;
- gắn với workspace hiện tại;
- pairing mới thay pairing code cũ của cùng workspace.

Admin pairing endpoint chỉ chấp nhận request từ máy local chạy PersonalAI.

Android claim code qua:

```http
POST /api/companion/pairing/claim
```

Body:

```json
{
  "code": "...",
  "deviceName": "Pixel"
}
```

Kết quả trả device token **một lần duy nhất**.

## Device token

Device token:

- random 256-bit;
- gửi dưới dạng Bearer token;
- backend không lưu plaintext;
- backend chỉ lưu SHA-256 hash;
- so sánh bằng constant-time comparison;
- revoke server-side có hiệu lực ngay.

Device store mặc định:

```text
%LOCALAPPDATA%\PersonalAI\Companion\devices.json
```

Override:

```text
Companion:Root
Companion__Root
```

Giới hạn:

- tối đa 10 thiết bị / workspace.

## Android secure storage

Ứng dụng Android không lưu device token plaintext trong SharedPreferences.

Token được mã hóa bằng:

- Android Keystore;
- AES-256-GCM;
- key riêng của app.

SharedPreferences chỉ lưu ciphertext + IV cùng metadata không bí mật như server URL, device name và workspace ID.

## Workspace isolation

Pairing code được tạo trong workspace nào thì device token bị khóa vào workspace đó.

Companion authentication middleware:

1. xác thực Bearer token;
2. lấy workspace từ device record;
3. ghi đè `X-PersonalAI-Workspace` bằng workspace đã pair;
4. sau đó mới chạy Workspace Validation.

Client không thể gửi một workspace header khác để đổi scope của token.

## Transport policy

Mặc định:

```text
Companion:AllowInsecureHttp = false
```

Pairing claim và client API yêu cầu HTTPS.

Để test hoặc dùng HTTP trên LAN tin cậy, người dùng phải bật explicit:

```text
Companion__AllowInsecureHttp=true
```

Android app cũng yêu cầu người dùng bật checkbox riêng trước khi chấp nhận URL `http://`.

Hai phía cùng phải opt-in.

Không có TLS certificate bypass trong Android app.

Nếu dùng HTTPS self-signed, certificate phải được thiết bị tin cậy theo Android trust configuration của người dùng.

## Client API

Sau khi pair, Android dùng:

```http
GET  /api/companion/client/me
GET  /api/companion/client/core
GET  /api/companion/client/tasks
POST /api/companion/client/chat
```

Tất cả endpoint trên yêu cầu:

```http
Authorization: Bearer <device-token>
```

## Companion chat

Android chat dùng cùng Chat Context pipeline với desktop:

- Memory;
- Documents/RAG;
- Task Context;
- workspace isolation;
- AI provider hiện tại.

v1.5 refactor desktop và Android qua chung `IChatTurnService` để tránh hai chat pipeline lệch nhau.

Khác biệt quan trọng:

```text
Android chat -> UseTools = false
```

Backend cưỡng chế giá trị này, không tin field từ client.

Do đó Android v1.5 không thể:

- tạo Tool Proposal;
- chạy Workspace tool;
- chạy Computer Use;
- chạy Browser Agent;
- gọi Connector;
- chạy Development Agent.

## Tasks

```http
GET /api/companion/client/tasks
```

chỉ trả Task list trong workspace đã pair.

v1.5 không map các endpoint:

- execute-next;
- retry;
- resume;
- cancel;
- prepare;
- create task

vào namespace companion.

Task mutation từ Android chưa được mở.

## Desktop device management

Desktop local có:

```http
GET    /api/companion/admin/devices
DELETE /api/companion/admin/devices/{deviceId}?confirmed=true
```

Revoke yêu cầu confirmation.

Khi revoke:

- hash token bị xóa khỏi device store;
- request Android tiếp theo trả 401;
- audit event được ghi.

## Audit

Audit agent mới:

```text
companion
```

Các event chính:

- `companion.pairing.prepare`
- `companion.pairing.claim`
- `companion.device.revoke`
- Android chat vẫn ghi `chat.completed` với agent `companion`.

Audit không lưu:

- pairing code;
- device token;
- plaintext secret.

## Android app

Project:

```text
android/PersonalAI.Companion/
```

App là Android native project:

- Java;
- minSdk 26;
- targetSdk 35;
- versionName 1.5.0.

Không cần WebView.

UI hỗ trợ:

- server URL;
- device name;
- pairing code;
- explicit HTTP opt-in;
- core/provider status;
- chat;
- read-only task list;
- local disconnect.

Local disconnect chỉ xóa encrypted token khỏi điện thoại. Để thu hồi quyền thật sự, dùng desktop revoke.

## Network access

PersonalAI ASP.NET Core mặc định thường chỉ listen localhost.

Để điện thoại vật lý truy cập, người dùng phải cấu hình server listen trên interface phù hợp và firewall/TLS phù hợp.

v1.5 **không tự động mở firewall**, không tự bind mọi interface và không tự cấp certificate.
