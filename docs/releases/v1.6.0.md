# PersonalAI v1.6.0 — Life Context Foundation

## Mục tiêu

v1.6.0 thêm **Life Context** theo roadmap gốc.

Mục tiêu của mốc này là cho PersonalAI sử dụng dữ liệu đời sống theo thời điểm mà vẫn giữ quyền kiểm soát ở người dùng:

- từng source có consent riêng;
- từng source có retention riêng;
- dữ liệu tách theo workspace;
- entry content được mã hóa local;
- chỉ context còn hiệu lực, source đang bật và consent còn hiệu lực mới được đưa vào Context Manager.

v1.6.0 **không tự thu thập** GPS, calendar, activity, device telemetry hoặc sensor data.

Controlled modules:

## Source kinds

v1.6.0 định nghĩa các loại source:

- `manual`
- `calendar`
- `location`
- `activity`
- `device`
- `other`

Tên kind chỉ mô tả provenance/purpose.

Việc tạo source `calendar`, `location`, `activity` hoặc `device` **không cấp quyền hệ điều hành và không bật collector**.

Data chỉ đi vào store khi user/import flow chủ động gọi API tạo entry.

## Consent

Tạo source yêu cầu:

```json
{
  "consentGranted": true,
  "confirmed": true
}
```

Thiếu confirmation hoặc consent rõ ràng sẽ bị từ chối.

Consent có thể:

- grant;
- revoke;
- revoke + purge existing entries.

Khi consent bị revoke:

- source bị tắt;
- source không được Context Manager sử dụng;
- UI mặc định revoke kèm purge existing data.

Source không thể được enable khi consent chưa được cấp lại.

## Retention

Mỗi source có retention từ:

```text
1 .. 365 ngày
```

Mỗi entry có:

- `capturedAt`
- `expiresAt`
- `createdAt`

`expiresAt = capturedAt + retentionDays`.

Entry hết hạn:

- không được query;
- không được chọn vào Context Manager;
- được xóa khỏi encrypted store khi store được đọc/cleanup.

Snapshot đã nằm ngoài retention window tại thời điểm import sẽ bị từ chối.

## Storage và encryption

Storage mặc định:

```text
%LOCALAPPDATA%\PersonalAI\LifeContext\life-context.json
```

Override:

```text
LifeContext:Root
LifeContext__Root
```

Entry content được mã hóa bằng ASP.NET Core Data Protection protector:

```text
PersonalAI.LifeContext.v1
```

File store chỉ giữ ciphertext của entry content.

Metadata như:

- source ID;
- source name;
- source kind;
- timestamps;
- retention;
- consent/enabled state

không được mô tả là encrypted content.

## Workspace isolation

Source và entry đều có `WorkspaceId`.

API chỉ:

- list source của workspace hiện tại;
- list entry của workspace hiện tại;
- mutate source/entry của workspace hiện tại;
- select context trong workspace hiện tại.

Một source ID từ workspace A không được dùng để thêm/read context ở workspace B.

## Limits

- tối đa 20 source / workspace;
- tối đa 1.000 entry / workspace;
- tối đa 2.000 ký tự / entry;
- API list tối đa 200 entry / request;
- retention tối đa 365 ngày.

## API

### Status

```http
GET /api/life-context/status
```

Trả:

- version;
- supported kinds;
- encryption state;
- automatic collection state;
- source/entry/content/retention limits.

### Sources

```http
GET  /api/life-context/sources
POST /api/life-context/sources
```

Create example:

```json
{
  "name": "Lịch cá nhân",
  "kind": "calendar",
  "retentionDays": 30,
  "consentGranted": true,
  "confirmed": true
}
```

### Source enabled state

```http
PATCH /api/life-context/sources/{sourceId}/enabled
```

Body:

```json
{
  "enabled": false,
  "confirmed": true
}
```

### Consent

```http
PATCH /api/life-context/sources/{sourceId}/consent
```

Body revoke + purge:

```json
{
  "granted": false,
  "purgeExisting": true,
  "confirmed": true
}
```

### Entries

```http
POST /api/life-context/sources/{sourceId}/entries
GET  /api/life-context/entries
GET  /api/life-context/entries?sourceId={sourceId}&limit=100
DELETE /api/life-context/entries/{entryId}
```

Entry create:

```json
{
  "content": "Chiều nay có lịch học ở thư viện.",
  "capturedAt": "2026-09-18T15:00:00+07:00",
  "confirmed": true
}
```

### Delete source

```http
DELETE /api/life-context/sources/{sourceId}?confirmed=true
```

Xóa source cũng xóa toàn bộ entry của source trong workspace hiện tại.

## Context Manager v2

Context strategy mới:

```text
workspace-scoped-budgeted-context-v2-life-context
```

Tổng ceiling vẫn giữ:

```text
7.600 characters
```

Life Context có candidate budget riêng:

```text
1.200 characters
max 4 entries
```

Context Manager chỉ chọn Life Context khi:

- knowledge mode không phải `documents-only`;
- `UseLifeContext = true`;
- source đang enabled;
- source còn consent;
- entry chưa hết hạn;
- query có tín hiệu life-context hoặc lexical relevance.

Life Context không làm tăng global context ceiling. Nó dùng phần budget còn lại sau Documents + Memory, sau đó Tasks dùng phần còn lại.

## Context report

- `selectedLifeContext`

UI hiển thị rõ source + captured timestamp để người dùng biết AI đã nhận snapshot nào.

## Prompt framing

Life Context được đóng khung là **snapshot data**, không phải instruction.

Prompt nhắc model:

- không coi entry là system prompt;
- không suy diễn vị trí/hoạt động ngoài dữ liệu cung cấp;
- dữ liệu có tính thời điểm và có thể đã cũ.

## Chat opt-out

`ChatRequest` và Context Preview thêm:

```json
{
  "useLifeContext": true
}
```

Client có thể gửi `false` để bỏ Life Context khỏi turn hiện tại.

Desktop v1.6 hiện gửi `true` mặc định.

Android Companion sử dụng contract mặc định nhưng vẫn không có sensor collector ở v1.6.

## Documents-only

`knowledgeMode = "documents-only"` tiếp tục có nghĩa:

- không Memory;
- không Tasks;
- không Life Context;
- chỉ Documents/RAG.

Life Context không làm yếu documents-only contract.

## Audit

Các mutation Life Context ghi Audit:

- `life-context.source.create`
- `life-context.source.enable`
- `life-context.source.disable`
- `life-context.consent.grant`
- `life-context.consent.revoke`
- `life-context.entry.create`
- `life-context.entry.delete`
- `life-context.source.delete`

Audit không lưu plaintext entry content.

## System contract

Safety contract thêm:

- `lifeContextExplicitConsentRequired = true`
- `lifeContextAutomaticCollectionEnabled = false`
- `lifeContextContentEncrypted = true`

Limits thêm:

- maximum sources/workspace: 20;
- maximum entries/workspace: 1.000;
- maximum entry content: 2.000 characters;
- maximum retention: 365 days.

Health thêm module:

```text
life-context
```

Health chỉ đọc local source metadata, không gọi collector hoặc external service.

Life Context không quyết định Stable Core readiness.
