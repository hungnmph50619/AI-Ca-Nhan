# PersonalAI v1.7.0 — Decision Engine

## Mục tiêu

v1.7.0 thêm **Decision Engine** theo roadmap gốc.

Mục tiêu của mốc này là giúp người dùng so sánh lựa chọn dựa trên context đang có trong PersonalAI mà không biến recommendation thành hành động tự động.

Decision Engine dùng:

- Memory;
- Documents / RAG;
- Tasks;
- Life Context đã consent.

Nó không có tool execution, không có auto-action và không lưu nội dung phân tích mặc định.

## Release contract

- Version: `1.7.0`
- API contract: `1`
- Channel: `controlled`

`controlledModules` gồm:

- `computer-use`
- `browser-agent`
- `connectors`
- `software-development`
- `android-companion`
- `life-context`
- `decision-engine`

## Decision contract

Mọi response phân tích luôn mang:

- `requiresUserDecision = true`
- `autoActionEnabled = false`
- `toolExecutionEnabled = false`
- `persisted = false`

Decision Engine không có endpoint `execute`, `apply`, `run` hay `schedule`.

Recommendation không phải authorization để Tool Framework hoặc Task Engine hành động.

## Status API

```http
GET /api/decisions/status
```

Trả:

- version;
- capability state;
- maximum question/options/criteria;
- context kinds;
- no-auto-action/no-tool/no-persistence guardrails.

## Preview context

```http
POST /api/decisions/preview
```

Preview:

- validate decision request;
- gọi Context Manager;
- trả ContextSelectionReport;
- trả document sources;
- không gọi Gemini/OpenAI;
- không lưu analysis.

Ví dụ request:

```json
{
  "question": "Nên chọn phương án nào?",
  "options": [
    "Phương án A",
    "Phương án B"
  ],
  "criteria": [
    "Chi phí",
    "Thời gian",
    "Rủi ro"
  ],
  "constraints": "Không vượt ngân sách đã đặt.",
  "useKnowledge": true,
  "useMemory": true,
  "useTaskContext": true,
  "useLifeContext": true
}
```

## Analyze

```http
POST /api/decisions/analyze
```

Flow:

```text
user decision request
        ↓
validation
        ↓
Context Manager
        ├─ Memory
        ├─ Documents / RAG
        ├─ Tasks
        └─ consented Life Context
        ↓
Decision analysis guardrails
        ↓
active AI provider
        ↓
analysis + trade-offs + uncertainty
        ↓
user decides
```

Không có Tool Orchestration trong flow này.

## Input limits

- question: tối đa 4.000 ký tự;
- options: 2–8 lựa chọn;
- mỗi option: tối đa 240 ký tự;
- criteria: tối đa 8;
- mỗi criterion: tối đa 180 ký tự;
- constraints: tối đa 2.000 ký tự;
- option/criterion trùng lặp được deduplicate không phân biệt hoa thường.

## Analysis contract

Prompt v1.7 yêu cầu model:

1. tóm tắt quyết định;
2. nêu evidence/context liên quan;
3. so sánh tất cả lựa chọn theo tiêu chí của người dùng;
4. phân biệt dữ kiện, suy luận, giả định và phần thiếu;
5. trình bày trade-off/risk/uncertainty;
6. chỉ recommendation khi evidence đủ;
7. nêu điều gì có thể làm recommendation thay đổi;
8. kết thúc bằng việc quyết định cuối cùng thuộc về người dùng.

Decision Engine không cho phép model tuyên bố đã thực thi recommendation.

## Context boundary

Decision Engine dùng chính `IContextManagerService` đang phục vụ chat.

Không có retrieval pipeline thứ hai.

Context report vẫn có:

- workspace ID;
- strategy;
- selected Memory/Documents/Tasks/Life Context;
- character budget;
- document sources.

Life Context vẫn chỉ được chọn khi source có consent/enabled/retention hợp lệ.

Documents-only mode không được Decision Engine dùng; engine luôn chạy normal context mode và từng loại context được bật/tắt bằng flag riêng.

## Privacy

v1.7 không tạo Decision database.

Không lưu:

- question;
- options;
- criteria;
- constraints;
- analysis text.

Audit chỉ ghi metadata:

- `decision.preview`
- `decision.analyze`
- random decision ID;
- workspace;
- result.

Private decision content không được ghi Audit.

## AI provider

`preview` không gọi provider.

`analyze` chỉ hoạt động khi Gemini/OpenAI hiện tại đã được cấu hình.

Nếu provider chưa cấu hình:

- request trả 503;
- không giả lập kết quả local;
- không lưu decision.

## Tool / action safety

Decision Engine:

- không implement `IPersonalAiTool`;
- không đăng ký trong Tool Registry;
- không inject `IToolOrchestrationService`;
- không gọi Task Engine;
- không tạo Undo record;
- không có automatic confirmation;
- không có scheduler.

Nếu người dùng muốn hành động dựa trên recommendation, đó là một request mới đi qua permission/confirmation hiện có.

## System capability contract

Safety contract thêm:

- `decisionEngineRequiresUserDecision = true`
- `decisionEngineAutoActionEnabled = false`
- `decisionEngineToolExecutionEnabled = false`
- `decisionEnginePersistsAnalyses = false`

Limits thêm:

- `decisionMaximumQuestionCharacters = 4000`
- `decisionMaximumOptions = 8`
- `decisionMaximumCriteria = 8`
