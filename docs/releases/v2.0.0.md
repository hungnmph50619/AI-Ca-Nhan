# v2.0.0 — Personal AI OS

v2.0.0 là mốc hợp nhất các subsystem đã xây từ Memory/RAG đến Hardening thành một **Personal AI OS contract** thống nhất. Bản này không mở Multi-Agent; Agent Framework bắt đầu ở v2.1.

## Mục tiêu

PersonalAI ở v2.0 phải có một bề mặt hệ thống duy nhất để trả lời ba câu hỏi:

1. hệ thống hiện có những capability nào;
2. capability nào thực sự sẵn sàng, capability nào vẫn controlled/foundation/unconfigured;
3. các guardrail nào vẫn đang khóa autonomy trước v2.1.

## OS layers

v2.0 gom capability thành 5 lớp:

- **Knowledge & Context** — Memory, Knowledge/RAG, Life Context;
- **Planning & Decision** — Tasks, Decision Engine;
- **Tools & Automation** — Tool Framework, Files, Automation, Software Development;
- **Device & External Interfaces** — Desktop, Browser, Connectors, Email, Calendar, Android;
- **Governance & Recovery** — Audit, Undo, Hardening.

## API mới

```http
GET /api/os/status
GET /api/os/manifest
```

`/api/os/status` trả trạng thái theo workspace hiện tại, readiness gate, governance flags và capability state động.

`/api/os/manifest` trả kiến trúc logic, capability map và ranh giới autonomy của mốc v2.0.

## Capability states

- `ready` — stable local capability đang hoạt động;
- `controlled` — capability hoạt động nhưng bị permission/confirmation/safety boundary kiểm soát;
- `foundation` — nền tích hợp tồn tại nhưng chưa phải provider-specific/full workflow;
- `unconfigured` — capability có code nhưng môi trường hiện tại chưa đáp ứng;
- `unavailable` — module không vượt readiness;
- `reserved` — dành cho roadmap sau.

## Email / Calendar boundary

Roadmap v2.0 yêu cầu hệ thống có Email và Calendar. v2.0 biểu diễn hai capability này một cách trung thực:

- **Email**: connector-backed read foundation; chưa có Gmail/Outlook OAuth, mailbox model hoặc send action riêng;
- **Calendar**: Life Context hỗ trợ calendar snapshot và connector foundation; chưa có provider-specific auto-sync/write.

Vì vậy UI/API không gắn nhãn hai capability này là `ready`; trạng thái là `foundation` khi lớp nền tương ứng hoạt động.

## Governance

v2.0 giữ nguyên các invariants của v1.9:

- workspace isolation;
- permission policy;
- explicit confirmation cho side effects;
- Audit;
- Undo;
- Hardening;
- backup/restore;
- autonomous agent loop = false;
- parallel tool calls = false;
- Multi-Agent Framework = false;
- Agent Orchestration = false.

## Readiness gate cho v2.1

`readyForV21Foundation` chỉ true khi các nền bắt buộc không unavailable:

- Workspace;
- Tasks;
- Tools;
- Audit;
- Hardening.

Desktop, external connector hoặc Android có thể `unconfigured` do môi trường mà không làm hỏng OS contract cục bộ.

## UI

Sidebar có mục **Personal AI OS**. Console hiển thị:

- số capability;
- ready / controlled / foundation;
- từng OS layer;
- trạng thái từng capability;
- ranh giới v2.0 trước Multi-Agent.

## Không có trong v2.0

- Multi-Agent Framework;
- agent messaging/orchestration;
- autonomous agent loop;
- automatic side-effect confirmation;
- provider-specific Gmail/Outlook/Calendar OAuth;
- autonomous coding/deployment loop.

Những phần agent bắt đầu ở **v2.1 — Multi-Agent** theo roadmap.
