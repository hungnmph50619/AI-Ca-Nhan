# v2.1.0 — Agent Framework

v2.1.0 là bước đầu tiên của giai đoạn Multi-Agent. Bản này tạo **Agent Framework có thể chạy được**, nhưng cố ý chưa triển khai Planner/Research/Developer/Reviewer/Security Agent riêng và chưa có Agent Orchestration.

## Contract

Mỗi executable agent có:

- `Id`;
- `Name`;
- `Role`;
- `Description`;
- `Capabilities`;
- `Tools`;
- `ContextKinds`;
- `UsesAiProvider`;
- `ToolExecutionEnabled`;
- `RequiresExplicitInvocation`;
- `ExecuteAsync(...)`.

Agent Registry kiểm tra id, capability, context kind và tool binding lúc khởi tạo. Tool binding phải trỏ tới tool thực sự có trong Tool Registry.

## Agent đầu tiên

`core.personal-assistant` là agent nền đầu tiên.

Nó có thể dùng Context Manager với:

- Memory;
- Knowledge / RAG;
- Tasks;
- Life Context.

Bound tool metadata:

- `local.clock`;
- `local.text_stats`.

Ở v2.1.0, hai tool trên **không được agent tự chạy**. Binding chỉ là allowlist metadata để các bản orchestration sau có thể mở theo policy.

## Execution boundary

Agent execution:

1. chỉ bắt đầu từ `POST /api/agents/{agentId}/execute` hoặc thao tác người dùng tương đương;
2. giới hạn goal 4.000 ký tự;
3. tối đa 20 message lịch sử;
4. tối đa 1 agent execution đồng thời;
5. dùng workspace hiện tại;
6. dùng Context Manager;
7. gọi AI provider để tạo kết quả;
8. ghi Audit;
9. không tự chạy tool;
10. không tự tạo automation/task side effect;
11. không agent-to-agent messaging;
12. không automatic delegation.

## API

```http
GET  /api/agents/status
GET  /api/agents
GET  /api/agents/{agentId}
POST /api/agents/{agentId}/execute
```

`/api/agents/status` công bố rõ:

- `automaticDelegationEnabled = false`;
- `agentMessagingEnabled = false`;
- `sharedTaskQueueEnabled = false`;
- `parallelAgentExecutionEnabled = false`;
- `toolExecutionEnabled = false`;
- `maximumConcurrentExecutions = 1`;
- next stage = `v2.1.1-planner-agent`.

## OS integration

Personal AI OS chuyển sang stage `v2.1`.

- thêm OS layer `Agent Framework`;
- thêm capability `agent-framework`;
- system health có module `agents`;
- `agents` chuyển từ reserved module sang controlled module;
- `MultiAgentFramework = true`;
- `AgentOrchestration = false`;
- OS readiness yêu cầu Agent Framework không unavailable.

## UI

Sidebar có mục **Agents**.

Người dùng có thể:

- xem agent đã đăng ký;
- xem role/capabilities/bound tools;
- chọn Context sources;
- nhập goal;
- bấm **Chạy agent**;
- xem kết quả.

UI luôn nhắc rằng v2.1.0 không tự chạy tool và không tự gọi agent khác.
