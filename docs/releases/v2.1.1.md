# v2.1.1 — Planner Agent

v2.1.1 triển khai **Planner Agent** theo roadmap: nhận một goal và chia goal thành kế hoạch có cấu trúc.

## Agent

`planning.planner` được đăng ký như executable agent thứ hai bên cạnh `core.personal-assistant`.

Planner khai báo các capability:

- `goal-decomposition`;
- `step-sequencing`;
- `dependency-analysis`;
- `capability-mapping`;
- `risk-identification`;
- `context-grounded-planning`.

Planner dùng Context Manager với Memory, Knowledge/RAG, Tasks và Life Context nếu người dùng bật các nguồn context tương ứng.

## Structured plan

Planner trả về `plan` trong `AgentExecutionResponse`:

```text
Plan
├── PlanId
├── Goal
├── Summary
├── Status = prepared
├── Steps[]
│   ├── Step
│   ├── Title
│   ├── Description
│   ├── DependsOn[]
│   ├── SuggestedRole
│   ├── RequiredCapabilities[]
│   ├── RequiresUserInput
│   └── ExpectedOutcome
├── OpenQuestions[]
├── Assumptions[]
├── Risks[]
├── CreatesTasks = false
├── DispatchesAgents = false
└── PersistsAutomatically = false
```

Giới hạn:

- 2–12 steps;
- dependency chỉ được trỏ về step trước;
- tối đa 8 open questions;
- tối đa 8 assumptions;
- tối đa 8 risks;
- tối đa 8 capability tags cho mỗi step.

Parser từ chối output không phải JSON hợp lệ, thiếu field bắt buộc, step numbering sai hoặc dependency trỏ tới chính/nằm sau step hiện tại.

## Suggested roles

Planner chỉ được gợi ý metadata role:

- `general-assistant`;
- `research`;
- `developer`;
- `office`;
- `operator`;
- `reviewer`;
- `security`;
- `user`.

Đây **không phải dispatch**. Các role agent chuyên biệt sẽ được triển khai dần từ v2.1.2 trở đi.

## API

Agent APIs giữ nguyên:

```http
GET  /api/agents/status
GET  /api/agents
GET  /api/agents/{agentId}
POST /api/agents/{agentId}/execute
```

Thêm Planner status:

```http
GET /api/planner/status
```

Planner status công bố step limits và các boundary:

- structured output = true;
- creates tasks = false;
- dispatches agents = false;
- persists plans = false;
- tool execution = false;
- explicit invocation = true.

## Safety boundary

v2.1.1 vẫn giữ:

- explicit user invocation bắt buộc;
- tối đa 1 agent execution đồng thời;
- agent tool execution = false;
- automatic delegation = false;
- agent messaging = false;
- shared task queue = false;
- parallel agent execution = false;
- Agent Orchestration = false;
- autonomous agent loop = false.

Planner không tự chuyển plan thành Task Engine tasks và không tự chạy bước nào trong plan.

## UI

Trong sidebar **Agents**:

- chọn Planner Agent;
- nhập goal;
- chọn Context sources;
- bấm **Lập kế hoạch**;
- xem plan theo từng step, dependency, suggested role, capability, outcome, open questions, assumptions và risks.

UI luôn hiển thị boundary rằng plan chỉ ở trạng thái prepared.
