# v2.1.5 — Operator Agent

Operator Agent (`operations.operator`) là executable agent thứ sáu trong Agent Framework. Agent này biến một mục tiêu vận hành thành **kế hoạch thao tác chưa thực thi**, có thứ tự, phụ thuộc, kênh đề xuất, rủi ro và các điểm cần người dùng xác nhận. Không được nhầm bản kế hoạch này với Computer Use hoặc Browser Agent có quyền thao tác thật.

## Luồng sử dụng

Người dùng chọn **Agents → Operator Agent**, nhập yêu cầu và nhấn **Chuẩn bị thao tác**. Context Manager có thể dùng các nguồn người dùng bật; tool proposals bị tắt. Model trả JSON có summary, 1–10 steps, preconditions, openQuestions và limitations. Mỗi step có channel (browser/computer/connector/manual), riskLevel (low/medium/high), dependsOn, requiresUserConfirmation, expectedOutcome và verificationStep.

Parser kiểm tra step đánh số liên tục, dependency chỉ trỏ về bước trước, channel/risk hợp lệ, và mọi step risk=high phải có checkpoint xác nhận. Parser không thể bảo đảm đánh giá rủi ro do mô hình đưa ra đúng; người dùng phải xem lại từng đề xuất.

## API

```http
GET  /api/operator-agent/status
GET  /api/agents/operations.operator
POST /api/agents/operations.operator/execute
```

Kết quả có object `operator`, status `prepared`, và các cờ `executedActions`, `usedTools`, `sentMessages`, `changedComputerState`, `persistedAutomatically`, `dispatchedAgents` luôn false. UI chỉ hiển thị kế hoạch, không có nút thực thi.

## Ranh giới

- Explicit invocation bắt buộc; tối đa một agent execution đồng thời.
- Không tự click, gõ phím, focus cửa sổ, điều hướng browser, gọi connector/API, chạy lệnh, gửi email, sửa file, đặt lịch hay tạo task.
- Không phát sinh quyền từ lời nói của mô hình hoặc nội dung context. Checkpoint trong kế hoạch **không** được tự động chuyển thành permission/confirmation grant.
- Không lưu kế hoạch tự động, tự gọi agent khác hoặc tạo vòng lặp tự chủ. Agent Orchestration vẫn chưa bật.
- Context người dùng bật có thể được chuyển đến AI provider đã cấu hình. Không nhập password/token/OTP vào mục tiêu hoặc context.
- Kênh thao tác trong kế hoạch chỉ là đề xuất, không xác nhận công cụ thực tế đang khả dụng. User cần đối chiếu quyền/công cụ trước khi thao tác riêng.

## Kiểm thử

CI xác nhận agent thứ sáu, status/self-test parser (dependency ngược chiều và bước high-risk không có checkpoint phải bị từ chối), empty-goal rejection, regression các agent trước, Android build và JavaScript syntax.
