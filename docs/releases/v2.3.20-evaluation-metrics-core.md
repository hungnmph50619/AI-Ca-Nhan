# v2.3.20 — Evaluation Metrics Core

Bản này tiếp tục **v2.3 — Evaluation** theo roadmap và chuyển trọng tâm từ
minimap riêng lẻ sang lớp đo lường dùng chung cho toàn Personal AI.

## Metric catalog theo roadmap

Evaluation Framework chuẩn hóa tên cho chín nhóm metric:

- `memory.accuracy`
- `rag.accuracy`
- `tool.success_rate`
- `desktop.success_rate`
- `browser.success_rate`
- `code.success_rate`
- `task.success_rate`
- `latency.ms`
- `cost`

Catalog chỉ định **tên và contract**. v2.3.20 không tự bịa số liệu cho module
chưa có evaluator tương ứng.

## Tổng hợp kết quả

Thêm `EvaluationMetricsAggregator` để tổng hợp tối đa 1000
`EvaluationResult`:

- số case;
- average/min/max score;
- tổng số lỗi;
- phân bố lỗi;
- average/min/max cho từng metric thực sự có dữ liệu;
- breakdown theo category.

API mới:

`POST /api/evaluation/summarize`

Status endpoint cũng công bố `roadmapMetrics` và giới hạn số kết quả được
tổng hợp.

## Biên an toàn

Tổng hợp hoàn toàn deterministic/local, không gọi Gemini/OpenAI, không tự
suy ra metric còn thiếu và không tự chọn model/candidate. Regression Dataset,
Agent Benchmark và Model Comparison vẫn là các bước kế tiếp của v2.3.
