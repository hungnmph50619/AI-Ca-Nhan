# v2.3.21 — Regression Dataset foundation

Bản này triển khai bước **Regression Dataset** trong giai đoạn v2.3
Evaluation của roadmap.

## Mục tiêu

Lưu các tình huống kiểm thử thực tế để có thể dùng lại ở các lần đánh giá sau,
thay vì mỗi lần phải nhập case thủ công.

## Storage

Mặc định:

`%LOCALAPPDATA%\PersonalAI\Evaluation\regression-dataset.db`

Có thể override bằng `Evaluation:Root`.

Dataset:

- lưu SQLite cục bộ;
- tách theo workspace hiện tại;
- tối đa 500 case mỗi workspace;
- tối đa 128 KiB cho mỗi payload;
- case ID duy nhất trong workspace;
- có cờ `enabled`;
- lưu `input`, `expected`, `category`, metadata và timestamps.

## API

- `GET /api/evaluation/regression/status`
- `GET /api/evaluation/regression`
- `GET /api/evaluation/regression/{caseId}`
- `POST /api/evaluation/regression`
- `PUT /api/evaluation/regression/{caseId}`
- `DELETE /api/evaluation/regression/{caseId}`
- `GET /api/evaluation/regression/export`

Create/update/delete được ghi vào Audit Foundation.

## Phạm vi chủ đích

v2.3.21 mới là **kho regression cases**. Bản này chưa tự chạy toàn bộ dataset,
chưa đánh giá agent end-to-end, chưa so sánh Model A/B/C và chưa tự chọn model.
Các bước đó thuộc Agent Benchmark và Model Comparison tiếp theo trong roadmap.

Không nên đưa password, API key hoặc bí mật khác vào regression dataset.
