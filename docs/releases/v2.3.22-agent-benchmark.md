# v2.3.22 — Agent Benchmark foundation

Bản này triển khai bước **Agent Benchmark** trong roadmap v2.3 Evaluation,
sử dụng chính Regression Dataset của v2.3.21 làm nguồn case.

## Regression case dành cho benchmark

Category:

`agent.benchmark`

Input mẫu:

```json
{
  "agentId": "core.personal-assistant",
  "goal": "Tóm tắt nội dung được cung cấp.",
  "useKnowledge": false,
  "useMemory": false,
  "useTaskContext": false,
  "useLifeContext": false
}
```

Expected hỗ trợ deterministic checks:

```json
{
  "contains": ["ý chính"],
  "notContains": ["SECRET"],
  "minimumLength": 40
}
```

## API

`POST /api/evaluation/benchmark/agents/run`

Request phải có:

`confirmExternalExecution: true`

vì agent có thể gọi Gemini/OpenAI theo cấu hình hiện tại và có thể phát sinh
latency/cost. Benchmark **không tự chạy nền**.

Có thể chỉ định `caseIds` hoặc để trống để chạy các case
`agent.benchmark` đang bật. Mặc định tối đa 10 case, hard limit 20 case/lần.

## Báo cáo

Mỗi case ghi:

- pass/fail;
- score 1/0;
- latency;
- provider/model;
- các expected check bị thiếu hoặc vi phạm.

Báo cáo tổng có pass rate và average latency.

## Giới hạn

Bản này chưa làm Model Comparison và không tự kết luận model nào tốt hơn.
Nó chỉ chạy tuần tự các agent đã được chỉ định rõ trong regression case,
giữ nguyên giới hạn không chạy agent song song của Agent Framework.
