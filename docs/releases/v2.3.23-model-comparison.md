# v2.3.23 — Model Comparison

Bản này hoàn thành bước **Model Comparison** trong roadmap v2.3 Evaluation.

## Cách hoạt động

Model Comparison nhận từ 2 đến 5 `AgentBenchmarkReport` đã chạy trên cùng
workspace và cùng tập regression case. Candidate đầu tiên được dùng làm
**baseline kỹ thuật** để tính delta; baseline không có nghĩa là model tốt nhất.

API:

`POST /api/evaluation/model-comparison`

Ví dụ khung request:

```json
{
  "candidates": [
    { "label": "Model A", "report": { "...": "AgentBenchmarkReport A" } },
    { "label": "Model B", "report": { "...": "AgentBenchmarkReport B" } }
  ]
}
```

## Kiểm tra trước khi so sánh

- cùng workspace;
- cùng tập case ID;
- cùng title và agentId cho từng case;
- report có counter/passRate nhất quán;
- không có case ID trùng;
- latency/score phải hữu hạn;
- tối đa 100 case, tối đa 5 candidate.

## Kết quả

Mỗi candidate có:

- provider/model nếu toàn report dùng cùng một giá trị;
- pass/fail;
- pass rate;
- average latency;
- delta pass rate so với baseline;
- delta latency so với baseline.

Ngoài ra trả bảng theo từng case để xem candidate nào pass/fail và lỗi expected
nào xuất hiện.

## Giới hạn chủ đích

Bản này **không tự đổi model**, không ghi đè AI settings, không chạy benchmark
ngầm, không tự tuyên bố model thắng và không deploy model. Để so A/B/C, người
dùng chạy cùng Regression Dataset với từng cấu hình model rồi đưa các báo cáo
vào endpoint comparison.

Đây là ranh giới cuối của **v2.3 Evaluation** trước khi chuyển sang
**v2.4 Self Improvement** trong roadmap.
