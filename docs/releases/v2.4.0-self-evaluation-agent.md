# v2.4.0 — Self Evaluation Agent

Bản này bắt đầu **Giai đoạn 15 — Self Improvement** theo roadmap.

Self Evaluation Agent hiện là một bộ phân tích **read-only, deterministic**.
Nó không sửa code, không tạo branch, không deploy và không tự chạy nền.

## Nguồn tín hiệu

Endpoint có thể đọc:

- Audit log của workspace hiện tại;
- Agent Benchmark reports;
- Model Comparison reports;
- User corrections được người dùng truyền rõ vào request.

API:

`POST /api/self-improvement/evaluate`

Ví dụ:

```json
{
  "auditLimit": 100,
  "benchmarks": [],
  "comparisons": [],
  "corrections": [
    {
      "area": "rag",
      "description": "Trợ lý trích sai nguồn ở tình huống X."
    }
  ]
}
```

## Weakness signals

Bản đầu phát hiện các nhóm tín hiệu:

- action trong audit bị failed/blocked/interrupted lặp lại;
- benchmark pass rate dưới 100%;
- benchmark latency cao;
- nhóm expected check thất bại lặp lại;
- candidate có pass rate thấp hơn baseline trong comparison;
- candidate có latency cao hơn baseline đáng kể;
- user correction lặp lại theo area.

Kết quả chỉ là **bằng chứng để xem xét**, chưa phải Improvement Proposal.

## Ranh giới

- `ReadOnly = true`
- `AutomaticChangesEnabled = false`
- không gọi AI provider;
- không tự quyết định sửa gì;
- không tạo code/branch/PR;
- không benchmark lại tự động;
- không deploy/rollback.

Bước tiếp theo theo roadmap là **v2.4.1 — Improvement Proposal**.
