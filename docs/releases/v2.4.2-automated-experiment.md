# v2.4.2 — Automated Experiment foundation

Bản này triển khai bước **Automated Experiment** theo roadmap nhưng giữ nguyên
guardrail Development Agent hiện tại.

API mới:

`POST /api/self-improvement/experiments/prepare`

Request nhận một `ImprovementProposal`, repository path tương đối và base
branch. Hệ thống tạo một experiment plan gồm:

- experiment ID ổn định;
- branch name dạng `experiment/<area>-<id>`;
- objective;
- verification plan;
- rollback plan;
- trạng thái Git và quyền Git write;
- yêu cầu human approval.

## Vì sao chưa tự tạo branch?

Development Agent hiện công bố rõ:

`GitWriteActionsEnabled = false`

và cấm git branch mutation. v2.4.2 **không âm thầm phá guardrail đó**.
Vì vậy khi quyền này vẫn tắt, experiment trả:

`status = branch-creation-blocked`

và:

`branchCreationPerformed = false`

Đây là trạng thái có chủ đích: hệ thống đã chuẩn bị experiment hoàn chỉnh nhưng
không tự thay đổi Git repository khi capability write chưa được cấp.

Khi một phiên bản sau bổ sung capability branch mutation có phạm vi hẹp,
có xác nhận người dùng và audit đầy đủ, chính plan này sẽ là đầu vào để tạo
branch thực tế.

## Ranh giới

- không sửa code;
- không commit/push/merge;
- không deploy;
- không nới Git permission;
- không bypass Development Agent;
- human approval luôn bắt buộc.

Bước tiếp theo trong roadmap là **v2.4.3 — Self Coding**, nhưng chỉ nên thực thi
trên experiment branch khi branch isolation thật sự khả dụng.
