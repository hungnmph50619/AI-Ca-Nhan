# v2.4.3 — Self Coding foundation

Bản này triển khai bước **Self Coding** theo roadmap với phạm vi kiểm soát chặt.

## Git isolation

Development Agent vẫn giữ:

`GitWriteActionsEnabled = false`

cho các thao tác Git write tổng quát. Bản này chỉ thêm capability hẹp:

`git-experiment-branch`

Capability này:

- bắt buộc xác nhận;
- chỉ tạo branch có tiền tố `experiment/`;
- yêu cầu repository sạch;
- chỉ switch từ base branch đã khai báo;
- không add/commit/push/pull/reset/merge/rebase;
- không cho experiment branch là main/master.

## Self Coding API

`POST /api/self-improvement/self-coding/run`

Request gồm:

- AutomatedExperimentPlan;
- ImprovementProposal;
- tối đa 8 file edit;
- xác nhận tạo branch;
- xác nhận thay đổi file.

Overwrite bắt buộc có `expectedSha256`. File write dùng lại
`IWorkspaceFileService.WriteTextAsync` nên giữ kiểm tra UTF-8, path sandbox,
kích thước và chống ghi đè phiên bản mới.

## Kết quả

Self Coding có thể:

1. xác minh base/experiment branch;
2. tạo và switch sang experiment branch nếu cần;
3. ghi các file đã được xác nhận;
4. audit từng file.

Nó **không**:

- tạo commit;
- push;
- merge;
- deploy;
- sửa main trực tiếp;
- ghi vào .git;
- tự sinh thêm edit ngoài request.

Các cờ kết quả `CommitCreated`, `Pushed`, `Merged` luôn false ở v2.4.3.

Bước tiếp theo theo roadmap là **v2.4.4 — Automated Review**.
