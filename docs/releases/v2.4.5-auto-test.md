# v2.4.5 — Auto Test

Bản này triển khai bước **Auto Test** trong Self Improvement.

API:

`POST /api/self-improvement/auto-test/run`

## Local regression phase

Auto Test đọc các Regression Dataset case đang bật của workspace và:

- chạy các category đã có evaluator trong Evaluation Engine;
- giữ nguyên input/expected/metadata;
- pass mặc định khi evaluator không trả error;
- nếu metadata có `minimumScore`, case còn phải đạt ngưỡng đó;
- category chưa có evaluator được đánh dấu `skipped`, không giả lập kết quả.

Tối đa 100 case/lần.

## Agent benchmark phase

Case `agent.benchmark` không tự gọi model.

Chỉ khi request có:

`includeAgentBenchmark = true`

và:

`confirmExternalExecution = true`

thì Auto Test mới gọi Agent Benchmark. Điều này giữ ranh giới chi phí/provider
đã có từ v2.3.22.

## Điều kiện chạy

Auto Test yêu cầu:

- cùng workspace;
- cùng experiment ID/branch giữa Experiment, Self Coding và Automated Review;
- branch hiện tại đúng `experiment/*`;
- chưa commit/push/merge/deploy.

## Kết quả

Kết quả gồm:

- pass/fail/skipped từng regression case;
- EvaluationSummary cho các evaluator local;
- AgentBenchmarkReport nếu được xác nhận;
- trạng thái `ready-for-promotion-review` hoặc `changes-required`.

`ready-for-promotion-review` chỉ có nghĩa là các test đã chạy không fail và
Automated Review trước đó sẵn sàng cho human decision. Nó **không tự promote**.

Các cờ luôn false ở v2.4.5:

- CommitCreated
- Pushed
- Merged
- Deployed

Bước tiếp theo theo roadmap là **v2.4.6 — Auto Deploy**; cần giữ human gate,
không được biến kết quả test thành quyền deploy tự động.
