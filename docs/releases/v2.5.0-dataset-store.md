# v2.5.0 — Dataset Store

Bản này bắt đầu **Personal Model Lab** bằng Dataset Store có version rõ ràng.

## Storage

Mặc định:

`%LOCALAPPDATA%\PersonalAI\ModelLab\datasets.db`

Có thể override root bằng `ModelLab:Root`.

Mỗi dataset thuộc workspace hiện tại và gồm:

- ID;
- name;
- description;
- created/updated timestamp;
- latest version metadata.

Nội dung dataset không nằm trực tiếp trên record dataset mà được lưu thành
các **immutable version snapshots**.

## Version contract

- dataset mới luôn bắt đầu ở version 1;
- version mới tăng tuần tự 2, 3, 4...;
- version cũ không bị update hoặc overwrite;
- mỗi snapshot lưu item count và SHA-256 của JSON payload;
- có `ExpectedLatestVersion` để chặn concurrent update/stale client;
- tối đa 100 versions mỗi dataset.

Giới hạn mặc định:

- 100 datasets/workspace;
- 2.000 items/version;
- 2 MiB payload/version.

## API

- `GET /api/model-lab/status`
- `GET /api/model-lab/datasets`
- `GET /api/model-lab/datasets/{id}`
- `GET /api/model-lab/datasets/{id}/versions`
- `GET /api/model-lab/datasets/{id}/versions/{version}`
- `POST /api/model-lab/datasets`
- `POST /api/model-lab/datasets/{id}/versions`

Create dataset và create version đều được audit.

## Phạm vi

v2.5.0 chỉ là **versioned Dataset Store**. Chưa training, chưa fine-tuning,
chưa tự biến regression data thành training data và chưa gọi AI provider.
Các bước Personal Model Lab tiếp theo phải sử dụng dataset version cụ thể
thay vì "latest" ngầm để bảo đảm reproducibility.
