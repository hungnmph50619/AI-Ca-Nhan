# v2.5.1 — Personal Dataset Builder

Roadmap yêu cầu: **Tạo dataset từ dữ liệu mà bạn cho phép.**

Bản này triển khai nguyên tắc đó bằng explicit selection. Dataset Builder
không tự scan toàn bộ dữ liệu cá nhân để lấy training data.

## API

`POST /api/model-lab/personal-dataset/build`

Request phải có:

- dataset đích;
- danh sách source selection cụ thể;
- `confirmUseSelectedPersonalData = true`.

## Source kinds

v2.5.1 hỗ trợ ba nguồn đã tồn tại trong Personal AI:

- `memory`: chọn chính xác memory GUID;
- `regression-case`: chọn chính xác regression case ID;
- `knowledge-chunk`: chọn chính xác document GUID + chunkIndex.

Không có chế độ "all memories", "all documents" hoặc "scan everything".

Memory disabled/expired và regression case disabled không được đưa vào dataset.

## Dataset output

Mỗi selected source được chuyển thành một JSON item có provenance:

- source kind;
- source ID;
- chunk index khi có;
- nội dung được chọn;
- metadata cần thiết.

Builder có thể:

- tạo dataset mới ở version 1; hoặc
- tạo immutable version tiếp theo của dataset đã có.

Version mới vẫn dùng SHA-256, item count và concurrency guard
`ExpectedLatestVersion` của Dataset Store v2.5.0.

## Privacy boundary

- không gọi Gemini/OpenAI;
- không tự chọn personal data;
- không tự thu thập background;
- không lấy source ngoài workspace hiện tại;
- chỉ build khi request xác nhận dữ liệu đã chọn.

Bước tiếp theo theo roadmap là **v2.5.2 — Data Cleaning**:
loại duplicates, bad examples, secrets và corrupt data.
