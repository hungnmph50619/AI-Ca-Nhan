# v2.5.10 — Sổ quản lý các phiên bản mô hình

Bản này bổ sung Model Registry ở phía trên Artifact Registry.

## Khác nhau giữa Artifact Registry và Model Registry

Artifact Registry quản lý file mô hình cụ thể, checksum, kích thước, metrics và lineage.

Model Registry quản lý:

- model family;
- version;
- artifact đang đại diện cho version đó;
- compatibility;
- runtime;
- deployment stage;
- production/canary state.

## Thành phần mới

- ModelVersionRecord
- ModelFamilySummary
- ModelDeploymentStages
- IModelRegistry
- JsonModelRegistry

## Deployment stages

- candidate
- staging
- canary
- production
- deprecated
- rejected
- archived

## Quy tắc chuyển trạng thái

candidate → staging / rejected / archived

staging → canary / rejected / archived

canary → production / staging / rejected / archived

production → deprecated

deprecated → archived

rejected → archived

archived là trạng thái cuối.

Artifact phải ở trạng thái validated trước khi model version được đưa lên staging, canary hoặc production.

Mỗi model family chỉ được có tối đa một production version.

## API

- GET /api/model-lab/models/status
- GET /api/model-lab/models/families
- GET /api/model-lab/models
- GET /api/model-lab/models/{modelId}
- GET /api/model-lab/models/family/{family}
- POST /api/model-lab/models
- POST /api/model-lab/models/{modelId}/stage

## Metadata model version

Mỗi version lưu:

- family
- version
- artifact ID và artifact SHA-256
- base model
- training method
- dataset ID/version/checksum
- compatible tasks
- runtime
- deployment stage
- notes
- created/updated timestamps

## Persistence

Registry được lưu theo workspace tại:

ModelLab/Registry/model-registry-{workspace}.json

## Kiểm thử tự động

Workflow model-lab-v2510.yml kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. train model nhỏ;
5. artifact tự đăng ký;
6. artifact chuyển validated;
7. model version được đăng ký;
8. candidate → staging → canary → production;
9. family summary phản ánh production version;
10. registry status đúng;
11. đăng ký trùng family + version bị trả 409.

## An toàn

v2.5.10 chỉ quản lý trạng thái registry.

Nó chưa tự:

- deploy model vào runtime;
- chuyển traffic thật;
- thay production LLM;
- rollback runtime;
- auto-promote candidate.

Các bước rollout thực tế nằm ở giai đoạn self-training/deployment tiếp theo.

Roadmap chuyển sang **v2.6.0 — Synthetic Data** để bắt đầu chu trình self-training có kiểm soát.
