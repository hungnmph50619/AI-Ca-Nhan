# v2.5.4 — Kiểm tra bộ dữ liệu trước khi huấn luyện

Bản này thêm lớp xác minh dataset trước khi một Training Job được phép đi tiếp tới các bước thực thi ở những phiên bản sau.

## Thành phần mới

- `ValidateTrainingDatasetRequest`
- `TrainingDatasetValidationReport`
- `TrainingDatasetValidationIssue`
- `ITrainingDatasetValidationService`
- `TrainingDatasetValidationService`

## API

`POST /api/model-lab/training/validate`

Ví dụ:

```json
{
  "datasetId": "demo",
  "sourceVersion": 1,
  "expectedContentSha256": null
}
```

## Những gì được kiểm tra

Validator đọc immutable dataset version hiện có và kiểm tra:

- dataset/version có tồn tại trong workspace hiện tại;
- checksum kỳ vọng nếu client truyền vào;
- exact duplicate;
- bad example;
- secret/API key/private key/token;
- corrupt JSON structure;
- top-level schema;
- chat messages phải có role/content hợp lệ;
- supervised pair dạng input + expected/output/completion;
- prompt + completion/output;
- content-only item được chấp nhận nhưng có warning;
- kích thước từng example;
- ước lượng token gần đúng.

## Tính bất biến

Validation chỉ đọc dataset nguồn.

Sau khi kiểm tra, service đọc lại cùng dataset version và xác minh:

- `ContentSha256` không đổi;
- `ItemCount` không đổi.

Report trả `sourceDatasetUnchanged=true` khi điều kiện này giữ nguyên.

## Điều kiện Valid

Dataset chỉ có `valid=true` khi:

- checksum khớp nếu được yêu cầu;
- có ít nhất một example;
- không có example bị reject;
- không có schema error;
- không có secret;
- không có corrupt item;
- dataset nguồn không thay đổi.

## Quan hệ với Data Cleaning

v2.5.4 dùng lại `IDataCleaningService` ở chế độ preview để không nhân đôi logic phát hiện:

- duplicate;
- bad example;
- secret;
- corrupt item.

Validation không tạo cleaned version và không sửa source dataset.

## Kiểm thử tự động

Workflow `model-lab-v254.yml` chạy:

1. restore;
2. build Release;
3. dotnet test;
4. khởi động API với Model Lab storage tạm;
5. tạo dataset hợp lệ và xác minh `valid=true`;
6. xác minh checksum sai trả `valid=false`;
7. tạo dataset có secret và xác minh bị reject;
8. tạo dataset trùng và xác minh duplicate ratio > 0;
9. xác minh source dataset không bị thay đổi.
