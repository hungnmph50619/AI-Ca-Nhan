# v2.5.5 — Lớp trung gian cho hệ thống huấn luyện

Bản này tách Model Lab khỏi một backend huấn luyện cụ thể.

## Mục tiêu

Các phiên bản sau có thể thay `MockTrainingProvider` bằng local trainer hoặc cloud provider mà không phải thay đổi Training Job contract.

## Thành phần mới

- `ITrainingProvider`
- `ITrainingProviderRegistry`
- `TrainingProviderCapabilities`
- `TrainingProviderValidationRequest/Result`
- `TrainingProviderStartRequest`
- `TrainingProviderExecutionHandle`
- `TrainingProviderProgress`
- `MockTrainingProvider`

## Khả năng của provider

Mỗi provider tự công bố:

- full fine-tune;
- LoRA;
- QLoRA;
- resume;
- metrics;
- cancellation;
- GPU;
- external service;
- danh sách training method hỗ trợ.

Planner/Training Executor về sau chỉ dựa trên contract này thay vì phụ thuộc implementation cụ thể.

## Mock provider

Provider `mock`:

- chạy hoàn toàn local;
- không dùng GPU;
- không gọi dịch vụ bên ngoài;
- không huấn luyện model thật;
- hỗ trợ method `full`;
- hỗ trợ trạng thái/cancel giả lập để test orchestration.

Bản v2.5.5 chưa nối mock provider vào background Training Executor. Phần thực thi job thuộc v2.5.6.

## API

- `GET /api/model-lab/training/providers`
- `POST /api/model-lab/training/providers/{providerId}/validate`

Validation không chạy training.

## Kiểm thử

Workflow `model-lab-v255.yml` kiểm tra:

1. restore;
2. build Release;
3. dotnet test;
4. khởi động API;
5. registry có mock provider;
6. capability của mock provider đúng;
7. cấu hình `full` hợp lệ;
8. cấu hình `lora` bị từ chối ở mock provider;
9. provider không tồn tại trả 404.

## Ranh giới an toàn

v2.5.5 không:

- chạy GPU;
- gọi cloud training;
- ghi model artifact;
- tự promote model;
- thay model production.
