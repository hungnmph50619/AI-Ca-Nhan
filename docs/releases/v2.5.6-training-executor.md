# v2.5.6 — Bộ thực thi huấn luyện

Bản này nối TrainingJob với TrainingProvider qua một background executor có hàng đợi bền vững.

## Thành phần mới

- TrainingExecutionRecord
- ITrainingExecutionStore
- JsonTrainingExecutionStore
- ITrainingExecutor
- TrainingExecutor

## Luồng

TrainingJob trạng thái pending
→ background runner tự đưa vào execution queue
→ provider validate
→ provider start
→ running
→ polling progress
→ completed / failed / cancelled

Hiện runner dùng mock provider mặc định để kiểm thử orchestration; chưa huấn luyện mô hình thật.

## Persistence và recovery

Execution state được lưu tại thư mục ModelLab bằng JSON theo workspace.

Nếu ứng dụng dừng khi execution đang running, lần khởi động sau sẽ đổi trạng thái đó thành interrupted thay vì completed.

## Timeout / cancel

- timeout mặc định: 300 giây;
- giới hạn timeout: 3600 giây;
- tối đa 1 execution đồng thời;
- nếu TrainingJob bị cancel, runner gọi cancel trên provider.

## Mock provider

Mock provider tự mô phỏng:
queued → running → completed

và trả metrics giả lập để smoke test toàn bộ pipeline.

## Kiểm thử

Workflow model-lab-v256.yml chạy:
1. restore;
2. build Release;
3. dotnet test;
4. chạy API;
5. tạo dataset mẫu;
6. tạo TrainingJob;
7. background runner tự nhặt job;
8. xác minh execution state bền vững chuyển thành completed.

## Giới hạn hiện tại

- chưa GPU;
- chưa local trainer thật;
- chưa cloud trainer;
- chưa artifact store;
- chưa model promotion.
