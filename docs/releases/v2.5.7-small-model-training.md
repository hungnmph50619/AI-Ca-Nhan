# v2.5.7 — Huấn luyện mô hình nhỏ có kiểm soát

Bản này bổ sung backend huấn luyện thật đầu tiên cho Model Lab, tập trung vào tác vụ phân loại văn bản nhỏ.

## Backend mới

`LocalSmallModelTrainingProvider`

- chạy hoàn toàn local;
- không gọi dịch vụ cloud;
- không cần GPU;
- dùng Multinomial Naive Bayes;
- nhận dataset dạng `input + expected`;
- yêu cầu ít nhất 2 example và ít nhất 2 nhãn;
- kiểm tra checksum dataset trước khi train;
- lưu artifact ứng viên riêng;
- không thay model production.

Training method:

`naive-bayes`

## Luồng

TrainingJob có `trainingMethod=naive-bayes`
→ TrainingExecutor chọn `local-small-model`
→ đọc immutable dataset version
→ huấn luyện classifier
→ tính training accuracy
→ lưu candidate artifact
→ execution completed

Các TrainingJob method khác vẫn đi qua mock provider ở giai đoạn hiện tại.

## Artifact

Artifact tạm được lưu tại:

`ModelLab/Candidates/{trainingJobId}.naive-bayes.json`

Nó chứa:

- loại mô hình;
- TrainingJob ID;
- dataset ID/version/checksum;
- labels;
- document counts;
- token counts;
- total tokens;
- vocabulary;
- thời gian tạo.

Kho Model Artifact chuẩn hóa sẽ được xây ở v2.5.9.

## Metrics

Execution metrics chứa:

- `trainingAccuracy`;
- số example;
- số labels;
- kích thước vocabulary;
- đường dẫn artifact;
- `candidateOnly=true`.

## Phạm vi sử dụng

Phù hợp để thử nghiệm:

- intent classifier;
- memory classifier;
- tool selector;
- email classifier;
- document category classifier.

Không dùng để thay LLM hội thoại chính.

## Kiểm thử tự động

Workflow `model-lab-v257.yml`:

1. restore;
2. build Release;
3. dotnet test;
4. chạy API;
5. tạo dataset intent có 2 nhãn;
6. tạo TrainingJob `naive-bayes`;
7. chờ background executor huấn luyện;
8. xác minh provider là `local-small-model`;
9. xác minh execution completed;
10. xác minh artifact tồn tại;
11. xác minh artifact có 2 labels và vocabulary;
12. xác minh metrics có training accuracy và `candidateOnly=true`.
