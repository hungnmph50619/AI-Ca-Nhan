# v2.5.9 — Kho lưu mô hình đã huấn luyện

Bản này chuẩn hóa artifact mô hình thành các bản ghi có lineage, checksum và trạng thái quản lý.

## Thành phần mới

- ModelArtifact
- ModelArtifactStatuses
- IModelArtifactStore
- JsonModelArtifactStore

## Metadata được lưu

Mỗi artifact có:

- Id
- Name
- Version
- BaseModel
- TrainingJobId
- DatasetId
- DatasetVersion
- DatasetSha256
- TrainingMethod
- ArtifactPath
- ArtifactSha256
- SizeBytes
- Metrics
- Status
- CreatedAt / UpdatedAt

## Trạng thái

- candidate
- validated
- rejected
- archived

Artifact mới luôn bắt đầu ở `candidate`.

## Tích hợp TrainingExecutor

Khi provider hoàn thành và trả `artifactPath`, TrainingExecutor tự:

1. kiểm tra file có tồn tại;
2. tính SHA-256;
3. đọc kích thước;
4. gắn lineage từ TrainingJob và Dataset;
5. lưu metrics;
6. đăng ký artifact vào registry với trạng thái candidate.

## API

- `GET /api/model-lab/artifacts/status`
- `GET /api/model-lab/artifacts`
- `GET /api/model-lab/artifacts/{artifactId}`
- `POST /api/model-lab/artifacts/{artifactId}/status`

## Persistence

Registry được lưu theo workspace trong:

`ModelLab/Registry/model-artifacts-{workspace}.json`

Artifact file thật vẫn nằm trong thư mục artifact tương ứng; registry lưu đường dẫn + checksum + metadata.

## Kiểm thử tự động

Workflow `model-lab-v259.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. tạo dataset;
5. huấn luyện local naive-bayes;
6. chờ artifact tự đăng ký;
7. xác minh status=candidate;
8. xác minh SHA-256 dài 64 ký tự;
9. xác minh sizeBytes > 0;
10. xác minh lineage dataset/training method;
11. chuyển status sang validated;
12. xác minh registry status cập nhật.
