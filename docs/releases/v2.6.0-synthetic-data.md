# v2.6.0 — Synthetic Data có kiểm soát

Bản này mở đầu giai đoạn self-training bằng cách cho AI tạo dữ liệu huấn luyện tổng hợp, nhưng luôn qua bước draft và xác nhận trước khi nhập vào dataset.

## Luồng

Dataset version bất biến
→ chọn instruction + count
→ xác nhận gửi seed tới AI
→ AI sinh JSON input/expected
→ lọc cấu trúc / trùng / secret
→ lưu Synthetic Draft
→ người dùng xác nhận commit
→ tạo dataset version mới

Version nguồn không bị sửa.

## Synthetic Draft

Mỗi draft lưu:

- workspace;
- dataset ID;
- source version;
- source SHA-256;
- provider;
- model;
- prompt SHA-256;
- instruction;
- số lượng yêu cầu;
- các item đã chấp nhận;
- số item bị loại;
- issues;
- thời gian tạo.

Draft được lưu riêng trong:

`ModelLab/Synthetic/synthetic-drafts-{workspace}.json`

## Giới hạn

- tối đa 50 item mỗi draft;
- tối đa 20 seed example được gửi cho AI;
- instruction tối đa 4.000 ký tự;
- input tối đa 4.000 ký tự;
- expected tối đa 1.000 ký tự;
- AI trả nhiều hơn Count thì chỉ lấy tối đa Count đã yêu cầu.

## Sàng lọc trước commit

Mỗi synthetic item phải:

- là JSON object;
- có input dạng chuỗi;
- có expected dạng chuỗi;
- không rỗng;
- không vượt giới hạn;
- không trùng source dataset;
- không trùng trong cùng draft;
- không chứa private key;
- không chứa bearer token;
- không chứa pattern API key độ tin cậy cao.

## Xác nhận bắt buộc

Generate cần:

`confirmExternalAi=true`

vì seed dataset được gửi tới provider AI đang chọn.

Commit cần:

`confirmCreateDatasetVersion=true`

Nếu dataset đã có version mới hơn source version của draft thì commit bị chặn và người dùng phải tạo draft mới.

## API

- `GET /api/model-lab/synthetic/status`
- `GET /api/model-lab/synthetic/drafts`
- `GET /api/model-lab/synthetic/drafts/{draftId}`
- `POST /api/model-lab/synthetic/generate`
- `POST /api/model-lab/synthetic/commit`

## Provenance

Prompt hash, provider, model, dataset version và source checksum được giữ lại để truy vết nguồn tạo dữ liệu.

Dataset version mới có note chứa draft ID và provider/model đã sinh dữ liệu.

## Kiểm thử tự động

Workflow `model-lab-v260.yml` không cần API key thật và kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. synthetic status trả version 2.6.0;
5. giới hạn tối đa 50 item;
6. thiếu xác nhận external AI bị chặn;
7. count > 50 bị chặn;
8. commit draft không tồn tại trả 404;
9. commit thiếu xác nhận bị chặn.

Việc sinh dữ liệu bằng provider thật được chạy khi máy người dùng đã cấu hình OpenAI hoặc Gemini.
