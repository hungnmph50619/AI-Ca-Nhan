# v2.6.1 — Critic Agent cho Synthetic Data

Bản này thêm một lớp đánh giá độc lập trước khi Synthetic Draft được phép commit thành dataset version mới.

## Hai tầng đánh giá

### 1. Local Critic

Luôn chạy được không cần API key và kiểm tra:

- cấu trúc input/expected;
- input quá ngắn;
- expected rỗng;
- input và expected giống nhau;
- expected có dấu hiệu meta/refusal;
- duplicate giữa các item;
- dấu hiệu secret/token.

Local Critic không tự khẳng định correctness semantic.

Nếu không có semantic review từ AI thì report luôn `passed=false`.

### 2. Semantic Critic AI

Khi request có:

`confirmExternalAi=true`

Critic gửi Synthetic Draft tới AI evaluator và yêu cầu chấm từng item theo thang 0–1:

- correctness;
- relevance;
- consistency;
- safety.

Overall score là mức thấp hơn giữa semantic score và local critic score.

Item chỉ được chấp nhận nếu:

- overall >= minimumScore;
- safety >= minimumScore;
- local critic >= minimumScore.

Ngưỡng mặc định:

`0.75`

## Critic độc lập với generator

Nếu có provider AI khác đã cấu hình, Critic ưu tiên provider khác với provider đã tạo Synthetic Draft.

Ví dụ:

OpenAI sinh dữ liệu
→ Gemini Critic

hoặc:

Gemini sinh dữ liệu
→ OpenAI Critic

Nếu chỉ có một provider được cấu hình thì Critic dùng provider đó nhưng vẫn chạy trong prompt/role đánh giá riêng.

## Critic Gate

Từ v2.6.1, Synthetic Draft chỉ được commit khi report mới nhất:

- tồn tại;
- `semanticReviewed=true`;
- `passed=true`.

Nếu chỉ qua local checks nhưng chưa có semantic review, commit bị chặn.

## API

- `GET /api/model-lab/synthetic/critic/status`
- `GET /api/model-lab/synthetic/critic/reports`
- `GET /api/model-lab/synthetic/critic/reports/{draftId}/latest`
- `POST /api/model-lab/synthetic/critic/review`

Synthetic status cũng có:

`criticPassRequiredForCommit=true`

## Persistence

Critic reports được lưu theo workspace tại:

`ModelLab/Synthetic/Critic/critic-reports-{workspace}.json`

Report giữ:

- draft ID;
- provider/model critic;
- semanticReviewed;
- minimumScore;
- accepted/rejected counts;
- từng dimension score;
- reason;
- passed;
- timestamp.

## Kiểm thử tự động

Workflow `model-lab-v261.yml` không cần API key thật và kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. critic status;
5. seed một Synthetic Draft local;
6. Local Critic phát hiện duplicate;
7. Local Critic phát hiện secret;
8. report chưa semantic review phải `passed=false`;
9. commit draft đó phải bị Critic Gate chặn;
10. synthetic status báo Critic pass là bắt buộc.
