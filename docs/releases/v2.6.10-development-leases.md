# v2.6.10 — Khóa repo và khóa file

Bản này bổ sung lease có expiry cho repository, branch và file để ngăn nhiều agent cùng ghi đè lên cùng tài nguyên.

## Resource scopes

Hỗ trợ ba loại lease:

- repository
- branch
- file

Lease có thứ bậc xung đột:

repository lease
→ chặn mọi branch/file lease của writer khác trong cùng repo

branch lease
→ chặn branch lease khác trên cùng branch
→ chặn file lease của writer khác trong cùng branch

file lease
→ chặn writer khác trên đúng file cùng branch
→ file khác trong cùng branch vẫn có thể được khóa riêng nếu không có branch/repo lease

## Lease metadata

Mỗi lease lưu:

- lease ID
- workspace ID
- owner ID
- resource type
- repository path
- branch
- file path
- acquiredAt
- expiresAt
- updatedAt

## Expiry

Lease có thời hạn từ:

- tối thiểu 30 giây
- tối đa 3600 giây

Lease hết hạn không còn được xem là active và được dọn khỏi store khi đọc active leases.

Nếu một agent chết giữa chừng, lease không khóa tài nguyên vĩnh viễn.

## Owner rules

Chỉ owner của lease mới được:

- renew
- release

Writer khác cố renew/release sẽ bị trả conflict.

Nếu cùng owner acquire lại đúng resource, lease được renew thay vì tạo duplicate lease.

## Persistence

Lease được lưu theo workspace tại:

`Development/Leases/development-leases-{workspace}.json`

## API

- `GET /api/development/leases/status`
- `GET /api/development/leases`
- `POST /api/development/leases/acquire`
- `POST /api/development/leases/renew`
- `POST /api/development/leases/release`

Conflict giữa writer trả HTTP 409.

## Roadmap Autopilot integration

RoadmapAutopilot giờ acquire branch lease trước khi tạo/sử dụng worktree của version tiếp theo.

Owner có dạng:

`roadmap-autopilot:{workspace}:{version}`

Lease dùng TTL tối đa 3600 giây.

Nếu agent khác giữ lease xung đột, Autopilot bị chặn trước khi ghi source code.

Sau khi run hoàn tất bình thường, Autopilot cố release lease.
Nếu process chết hoặc release thất bại, expiry vẫn giải phóng lease tự động.

## Capability

Development Agent công bố thêm:

`development-leases`

và limitation ghi rõ repo/branch/file writer được bảo vệ bằng lease có owner + expiry.

## Audit

Các action:

- `development.lease.acquire`
- `development.lease.renew`
- `development.lease.release`

Audit lưu lease ID, owner và resource metadata nhưng không lưu source content.

## Safety

v2.6.10 không:

- reset repo;
- force unlock bằng cách xóa code;
- cho writer khác chiếm lease chưa hết hạn;
- giữ lease vĩnh viễn;
- bypass worktree dirty-tree protection.

## Kiểm thử tự động

Workflow `development-v2610.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. status báo expiry + duplicate writer protection;
5. agent A giữ branch lease;
6. agent B acquire cùng branch → 409;
7. file lease dưới branch đang khóa → 409;
8. owner sai renew → 409;
9. owner đúng renew thành công;
10. release branch lease;
11. file A được khóa;
12. writer khác khóa cùng file → 409;
13. writer khác khóa file B → thành công;
14. repository lease bị chặn khi child leases đang active;
15. release child leases;
16. repository lease thành công;
17. child lease dưới repository lease → 409;
18. expired lease không còn active;
19. capability development-leases xuất hiện.
