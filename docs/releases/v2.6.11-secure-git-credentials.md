# v2.6.11 — Quản lý tài khoản Git an toàn

Bản này bổ sung Git credential reference và encrypted secret store cho Development subsystem.

## Mục tiêu

Git operation không nhận token/private key trực tiếp.

Luồng mới:

credential secret
→ encrypted local store
→ credentialRef
→ Git request dùng credentialRef
→ service giải mã nội bộ
→ process Git
→ secret không xuất hiện trong API/audit/output

## Credential kinds

Hỗ trợ:

- `https-token`
- `ssh-private-key`

Mỗi credential public metadata gồm:

- credentialRef;
- workspaceId;
- name;
- kind;
- username tùy chọn;
- hasSecret;
- createdAt;
- updatedAt.

API không trả secret hoặc encrypted blob.

## Encryption

Secret được mã hóa bằng ASP.NET Core Data Protection với purpose riêng:

`PersonalAI.GitCredentials.v1`

Persisted state chỉ lưu:

`EncryptedSecret`

Không lưu plaintext token/private key.

## HTTPS token execution

Với `https-token`:

1. credentialRef được resolve trong workspace hiện tại;
2. token được giải mã trong memory;
3. Authorization header được đưa vào Git bằng process environment;
4. token không nằm trong Git command arguments;
5. `GIT_TERMINAL_PROMPT=0` ngăn prompt credential ngoài kiểm soát.

Username mặc định:

`x-access-token`

nếu credential không cấu hình username.

## SSH private key execution

Với `ssh-private-key`:

1. private key được giải mã trong memory;
2. ghi vào temporary key file chỉ cho process hiện tại;
3. Unix permission là user read/write;
4. Git dùng `GIT_SSH_COMMAND` với key file đó;
5. temporary key luôn được cleanup trong `finally`, kể cả timeout/cancel/process error.

Không disable host-key verification.

## Git request integration

Các request network Git giờ có thêm optional:

`credentialRef`

Áp dụng cho:

- fetch;
- pull --ff-only;
- push.

Nếu không truyền credentialRef thì Git tiếp tục dùng credential mechanism mặc định của môi trường như trước.

## API quản lý credential

- `GET /api/development/git-credentials/status`
- `GET /api/development/git-credentials`
- `POST /api/development/git-credentials`
- `DELETE /api/development/git-credentials`

Create yêu cầu:

`confirmStoreCredential=true`

Delete yêu cầu:

`confirmDeleteCredential=true`

Không có endpoint đọc/decrypt secret.

## Status

Credential status công bố:

- `secretsEncrypted=true`
- `secretsReturnedByApi=false`
- `plaintextPersistenceEnabled=false`
- `auditContainsSecrets=false`

Development Agent có thêm capability:

`git-credential-references`

## Audit

Credential lifecycle ghi:

- `development.git-credential.create`
- `development.git-credential.delete`

Audit chỉ lưu:

- credentialRef;
- kind;
- name;
- `secret:redacted`.

Git fetch/pull/push audit tiếp tục chỉ lưu remote/branch/operation metadata.

Token hoặc private key không được ghi vào audit reason.

## Workspace isolation

Credential chỉ resolve khi:

- credentialRef tồn tại;
- credential thuộc workspace hiện tại.

Credential của workspace khác không được resolve qua API/Git operation hiện tại.

## Safety

v2.6.11 không:

- trả secret qua GET/list;
- trả encrypted secret qua public model;
- persist plaintext credential;
- đưa token vào Git command line;
- log private key;
- disable SSH host verification;
- lưu SSH temp key sau process.
