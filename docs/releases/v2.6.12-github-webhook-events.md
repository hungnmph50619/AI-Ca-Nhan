# v2.6.12 — Nhận sự kiện trực tiếp từ GitHub

Bản này bổ sung GitHub webhook receiver có xác minh chữ ký, idempotency theo delivery ID và Development Event Bus persisted.

## Sự kiện hỗ trợ

- push
- pull_request
- pull_request_review
- workflow_run
- check_run
- release

Các event khác bị từ chối.

## Webhook secret

Webhook secret được cấu hình bằng:

`POST /api/development/github-webhook/configure`

Request yêu cầu:

`confirmStoreSecret=true`

Secret được mã hóa bằng ASP.NET Core Data Protection với purpose:

`PersonalAI.GitHubWebhook.v1`

Settings được tách theo workspace.

Public status không trả secret hoặc encrypted blob.

## Signature verification

Mọi delivery bắt buộc có:

- `X-GitHub-Event`
- `X-GitHub-Delivery`
- `X-Hub-Signature-256`

Signature phải ở dạng:

`sha256=<64 hex chars>`

Server tính HMAC-SHA256 trên raw request body bằng webhook secret rồi so sánh bằng:

`CryptographicOperations.FixedTimeEquals`

Signature sai hoặc thiếu trả HTTP 401.

Kể cả delivery ID đã xử lý trước đó, signature vẫn phải được xác minh trước khi trả duplicate result.

## Idempotency

`X-GitHub-Delivery` là idempotency key.

Nếu delivery đã tồn tại:

- không publish event thứ hai;
- trả `duplicate=true`;
- Event Bus giữ đúng một event cho delivery đó.

## Development Event Bus

Webhook không lưu toàn bộ raw GitHub payload vào Event Bus.

Nó chuẩn hóa thành `DevelopmentEventEnvelope` gồm:

- event ID;
- workspace ID;
- source=github;
- event type;
- delivery ID;
- repository full_name;
- action;
- ref;
- sha;
- number;
- status;
- conclusion;
- tag;
- receivedAt.

Việc chỉ giữ metadata cần thiết giúp giảm dữ liệu thừa và tránh persist header/credential ngoài ý muốn.

Event Bus được lưu theo workspace tại:

`Development/Events/development-events-{workspace}.json`

Giới hạn giữ tối đa 2000 event.

## Status

Webhook status công bố:

- `signatureRequired=true`
- `signatureAlgorithm=hmac-sha256`
- `deliveryIdRequired=true`
- `idempotencyEnabled=true`
- số delivery đã xử lý
- danh sách event được hỗ trợ

## Audit

Cấu hình webhook:

`development.github-webhook.configure`

Nhận delivery mới:

`development.github-webhook.receive`

Audit chỉ lưu:

- delivery ID;
- event type;
- repository;
- normalized event ID.

Webhook secret không được ghi vào audit.

## Safety

v2.6.12 không:

- nhận unsigned webhook;
- tin `X-GitHub-Delivery` mà bỏ qua signature;
- lưu raw request headers;
- lưu webhook secret plaintext;
- publish duplicate delivery lần hai;
- phát toàn bộ raw payload vào Event Bus;
- tự chạy CI repair hoặc merge khi nhận event.
