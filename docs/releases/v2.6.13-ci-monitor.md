# v2.6.13 — Bộ theo dõi CI

Bản này bổ sung CI Monitor cho Development subsystem, sử dụng `workflow_run` và `check_run` từ Development Event Bus của v2.6.12.

## Mục tiêu

- theo dõi trạng thái CI theo run;
- correlation nhiều webhook update về cùng một run;
- persist state qua restart;
- lưu failure log excerpt đã redact;
- persist timeout/cancel;
- giới hạn tối đa 3 vòng repair;
- chưa tự tải full GitHub Actions logs ở bản này.

## Correlation

v2.6.13 mở rộng DevelopmentEventEnvelope với:

`externalId`

GitHub webhook map:

- `workflow_run.id`
- `check_run.id`

vào externalId.

CI Monitor ưu tiên correlation bằng:

`event type + externalId`

Nếu externalId không có thì fallback về delivery ID.

Nhờ vậy:

workflow queued
→ workflow completed

của cùng GitHub workflow_run.id cập nhật cùng một CI record thay vì tạo hai run độc lập.

## CI state

Các state:

- queued
- in-progress
- completed
- cancelled
- timed-out

Mỗi CiRunRecord lưu:

- workspace;
- repository;
- source event type;
- latest delivery ID;
- external run ID;
- ref;
- SHA;
- state;
- conclusion;
- repairAttempts;
- maximumRepairAttempts;
- failureLogExcerpt;
- failureLogTruncated;
- firstSeenAt;
- updatedAt;
- completedAt.

## Repair budget

Hard limit:

`MaximumRepairAttempts = 3`

Chỉ CI run:

- state=completed;
- conclusion khác success

mới được yêu cầu repair.

Vòng:

1 → allowed  
2 → allowed  
3 → allowed  
4 → HTTP 409

Cancelled/timed-out run không được repair.

v2.6.13 chỉ persist và cấp repair budget. Nó chưa tự gọi coding agent để sửa; vòng tự sửa CI thực tế sẽ được orchestration ở các version tiếp theo.

## Failure log

API có thể lưu một failure log excerpt cho CI run.

Giới hạn:

`32,000 characters`

Trước khi persist, service redact các pattern phổ biến như:

- GitHub token;
- github_pat;
- OpenAI-style secret;
- AWS access key;
- Authorization header;
- Bearer credential.

Audit chỉ lưu độ dài/truncation metadata, không lưu raw failure log.

### Giới hạn hiện tại

Webhook GitHub không cung cấp full workflow log.

Vì vậy status công bố:

`fullGitHubLogDownloadEnabled=false`

v2.6.13 hỗ trợ nhận/lưu log excerpt an toàn, nhưng chưa tuyên bố tự tải full log từ GitHub API.

## Timeout

Endpoint timeout chuyển run sang:

- state=timed-out;
- conclusion=timed_out;
- completedAt được persist.

## Cancel

Endpoint cancel chuyển run sang:

- state=cancelled;
- conclusion=cancelled;
- completedAt được persist.

Các terminal state timeout/cancel không bị webhook cũ ghi đè lại khi refresh.

## Persistence

State được lưu theo workspace tại:

`Development/CI/ci-runs-{workspace}.json`

State gồm cả:

- repairAttempts;
- failure log excerpt;
- timeout;
- cancel.

## API

- `GET /api/development/ci/status`
- `GET /api/development/ci/runs`
- `GET /api/development/ci/runs/{runId}`
- `POST /api/development/ci/refresh`
- `POST /api/development/ci/runs/{runId}/failure-log`
- `POST /api/development/ci/runs/{runId}/repair`
- `POST /api/development/ci/runs/{runId}/timeout`
- `POST /api/development/ci/runs/{runId}/cancel`

## Status

CI status công bố:

- maximumRepairAttempts=3;
- timeoutPersisted=true;
- cancellationPersisted=true;
- failureLogsPersisted=true;
- fullGitHubLogDownloadEnabled=false.

Development Agent có capability:

`ci-monitor`

## Audit

Các action:

- `development.ci.failure-log`
- `development.ci.repair-request`
- `development.ci.timeout`
- `development.ci.cancel`

Failure log plaintext không được ghi vào audit.

## Kiểm thử tự động

Workflow `development-v2613.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. CI status version 2.6.13;
5. workflow queued event;
6. workflow completed/failure cùng external run ID;
7. hai delivery chỉ tạo một CI run;
8. failure log có secret được redact;
9. repair attempt 1 thành công;
10. repair attempt 2 thành công;
11. repair attempt 3 thành công;
12. repair attempt 4 bị HTTP 409;
13. check run được mark timeout;
14. check run khác được cancel;
15. persisted file không chứa secret;
16. audit không chứa secret;
17. restart application;
18. timeout/cancel vẫn còn;
19. repairAttempts vẫn bằng 3;
20. capability ci-monitor được công bố.
