# v2.6.2 — Xác minh nhiều tầng

Bản này ghép các kiểm tra synthetic data thành một Verification Pipeline thống nhất.

## Pipeline

Synthetic Draft
→ Source Integrity
→ Semantic Critic
→ Dataset Validation
→ Reference Verification
→ Evaluation Gate
→ Human Review tùy chọn
→ VERIFIED / REJECTED

Chỉ report có `status=verified` và `eligibleForTraining=true` mới được phép đi tiếp tới commit dataset version.

## 1. Source Integrity

Kiểm tra:

- source dataset version còn tồn tại;
- workspace khớp;
- SHA-256 của source version vẫn đúng với draft.

Nếu source thay đổi hoặc provenance không khớp thì pipeline fail.

## 2. Semantic Critic

Pipeline dùng Critic report mới nhất của v2.6.1.

Bắt buộc:

- semanticReviewed=true;
- passed=true;
- số item trong Critic report khớp số synthetic item.

## 3. Dataset Validation

Hệ thống tạo prospective dataset trong bộ nhớ:

source items + synthetic items

và kiểm tra:

- mỗi item là JSON object;
- có input;
- có expected;
- input/expected không rỗng;
- không duplicate;
- không có dấu hiệu private key, bearer token, API key hoặc password.

Không sửa source dataset trong bước này.

## 4. Reference Verification

Nếu source dataset có dạng classification:

- có từ 1 đến 100 nhãn;
- mỗi nhãn dài tối đa 120 ký tự;

thì `expected` của mọi synthetic item phải thuộc source label vocabulary.

Ví dụ:

source labels:
- calendar
- email

synthetic expected:
- calendar → hợp lệ
- email → hợp lệ
- banking → fail

Nếu source không phải classification dataset thì reference layer ghi rõ không áp dụng cứng và không tự suy đoán ground truth.

## 5. Evaluation Gate

Mặc định kiểm tra:

- critic average >= 0.80;
- safety average >= 0.90;
- synthetic ratio <= 0.50;
- synthetic draft phải có ít nhất 1 item.

Synthetic ratio:

synthetic items / (source items + synthetic items)

Ngưỡng có thể được truyền trong request nhưng luôn bị giới hạn phạm vi hợp lệ.

## 6. Human Review tùy chọn

Request có thể truyền:

`humanReviewed=true`

Khi đó `humanReviewDecision` phải là:

`approved`

nếu không pipeline fail.

Nếu không yêu cầu human review thì layer này được đánh dấu là không áp dụng bắt buộc.

## Trạng thái

Verification report có:

- `verified`
- `rejected`

và trường:

`eligibleForTraining`

Chỉ `verified + eligibleForTraining=true` mới được phép commit synthetic dataset.

## Commit Gate

Từ v2.6.2, SyntheticDataService yêu cầu đồng thời:

1. Synthetic Draft đã qua local filtering;
2. Semantic Critic report PASS;
3. Verification report mới nhất PASS;
4. Verification report phải tham chiếu đúng Critic report mới nhất;
5. Verification status phải là verified;
6. người dùng vẫn phải xác nhận `confirmCreateDatasetVersion=true`.

## API

- `GET /api/model-lab/synthetic/verification/status`
- `GET /api/model-lab/synthetic/verification/reports`
- `GET /api/model-lab/synthetic/verification/reports/{draftId}/latest`
- `POST /api/model-lab/synthetic/verification/run`

## Persistence

Verification report được lưu theo workspace tại:

`ModelLab/Synthetic/Verification/verification-reports-{workspace}.json`

Report giữ:

- draft ID;
- source version/checksum;
- Critic report ID;
- từng verification layer;
- critic average;
- safety average;
- synthetic ratio;
- dataset validation result;
- reference verification result;
- evaluation gate result;
- human review state;
- verified/rejected status;
- eligibleForTraining;
- timestamp.

## Audit

Mỗi lần verify đều ghi audit:

`model-lab.synthetic.verify`

với kết quả succeeded hoặc failed.

## Kiểm thử tự động

Workflow `model-lab-v262.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. verification status;
5. tạo source dataset;
6. seed synthetic draft;
7. seed semantic Critic PASS;
8. thử commit trước verification và phải bị chặn;
9. chạy đủ pipeline verification;
10. source integrity PASS;
11. Critic PASS;
12. dataset validation PASS;
13. reference verification PASS;
14. evaluation gate PASS;
15. human review optional layer PASS;
16. report có status=verified;
17. commit sau verification tạo dataset version mới;
18. source version cũ vẫn bất biến.

## An toàn

v2.6.2 chưa:

- tự train sau khi Verified;
- tự promote model;
- tự deploy model;
- tự bypass human confirmation khi commit;
- tự coi reference verification là semantic truth cho free-form datasets.
