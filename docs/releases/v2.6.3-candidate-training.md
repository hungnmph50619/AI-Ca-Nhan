# v2.6.3 — Huấn luyện mô hình ứng viên

Bản này nối dữ liệu Synthetic đã VERIFIED với TrainingJob và Model Registry để tạo model candidate có lineage đầy đủ, nhưng không thay đổi production.

## Luồng

Synthetic Draft VERIFIED
→ commit thành dataset version mới
→ Candidate Training Plan
→ TrainingJob
→ Training Executor
→ Model Artifact
→ Model Registry stage=candidate

## Điều kiện bắt buộc

Candidate training chỉ được bắt đầu khi:

- synthetic draft tồn tại;
- Verification report mới nhất có `status=verified`;
- `eligibleForTraining=true`;
- dataset version dùng để train mới hơn source version;
- committed dataset khớp chính xác source items + verified synthetic items;
- checksum dataset khớp;
- người dùng truyền `confirmStartTraining=true`.

## Candidate Training Plan

Plan lưu:

- Draft ID;
- Verification Report ID;
- dataset ID/version/checksum;
- TrainingJob ID;
- model family/version;
- compatible tasks;
- runtime;
- Artifact ID;
- Model Version ID;
- trạng thái;
- failure reason;
- timestamps.

Trạng thái:

- queued
- artifact-registered
- candidate-registered
- failed

## Sau khi training hoàn thành

TrainingExecutor:

1. đăng ký artifact;
2. kiểm tra TrainingJob có Candidate Training Plan hay không;
3. đăng ký model version vào Model Registry;
4. model version luôn bắt đầu ở stage `candidate`;
5. cập nhật plan thành `candidate-registered`.

Không có bước nào tự chuyển candidate lên staging/canary/production.

## API

- `GET /api/model-lab/candidate-training/status`
- `GET /api/model-lab/candidate-training/plans`
- `GET /api/model-lab/candidate-training/plans/{planId}`
- `POST /api/model-lab/candidate-training/start`

## Safety

Status của subsystem công bố:

- `verifiedDataRequired=true`
- `productionMutationEnabled=false`
- `explicitConfirmationRequired=true`

Do đó v2.6.3 không:

- train từ draft chưa verified;
- train từ dataset không khớp verified lineage;
- auto-promote;
- thay production model;
- chuyển traffic production.

## Kiểm thử tự động

Workflow `model-lab-v263.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. tạo source dataset;
5. seed Synthetic Draft + Critic + Verification VERIFIED;
6. commit thành dataset v2;
7. thiếu confirmStartTraining phải bị chặn;
8. tạo Candidate Training Plan;
9. background executor train local model;
10. artifact tự đăng ký;
11. Model Registry tự có model version stage=candidate;
12. candidate plan chuyển candidate-registered;
13. Model Registry phải có production=0.

## Bước tiếp theo

Tiếp tục roadmap v2.6.x với bước đánh giá candidate trước khi rollout.
