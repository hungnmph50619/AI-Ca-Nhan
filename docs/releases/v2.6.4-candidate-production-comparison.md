# v2.6.4 — So sánh mô hình mới với mô hình hiện tại

Bản này bổ sung lớp so sánh trực tiếp giữa model candidate và production trong Model Registry.

## Mục tiêu

So sánh hai model version cùng family theo các metric:

- accuracy;
- task success rate;
- average latency;
- average cost per case;
- regression pass rate.

Bản này không tự chọn model tốt hơn và không tự promote candidate.

## Điều kiện so sánh

Candidate và production phải:

- thuộc cùng workspace;
- thuộc cùng model family;
- là hai model version khác nhau;
- baseline phải có stage `production`;
- candidate không được ở stage `production`;
- được đo trên cùng `benchmarkId`;
- cùng `benchmarkSha256`;
- cùng số case.

Nếu không thỏa các điều kiện trên, comparison bị từ chối.

## Metric snapshot

Mỗi phía gửi:

- benchmarkId;
- benchmarkSha256;
- cases;
- accuracy;
- taskSuccessRate;
- averageLatencyMilliseconds;
- averageCostPerCase;
- regressionPassRate.

Rate phải nằm trong khoảng 0..1.
Latency và cost không được âm.

## Delta

Report lưu delta theo:

`candidate - production`

cho từng metric.

Report không có trường winner, recommended model hay auto decision.

## Tính tái lập

Mỗi comparison lưu:

- candidate model ID/version/artifact SHA;
- production model ID/version/artifact SHA;
- toàn bộ metric snapshot;
- benchmark ID/checksum;
- canonical input SHA-256.

Nhờ vậy cùng input benchmark có thể được kiểm chứng lại.

## API

- `GET /api/model-lab/model-comparisons/status`
- `GET /api/model-lab/model-comparisons`
- `GET /api/model-lab/model-comparisons/{comparisonId}`
- `POST /api/model-lab/model-comparisons`

Nếu `productionModelVersionId` không được truyền, service tự tìm production version của cùng family.

## Persistence

Reports được lưu theo workspace tại:

`ModelLab/Comparisons/registered-model-comparisons-{workspace}.json`

## Safety

Status công bố:

- `productionBaselineRequired=true`
- `sameBenchmarkRequired=true`
- `autoPromotionEnabled=false`
- `persistent=true`

Comparison không:

- đổi stage candidate;
- đổi stage production;
- thay traffic;
- tự promote;
- tự archive production.

## Kiểm thử tự động

Workflow `model-lab-v264.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. seed production + candidate cùng family;
5. chạy comparison trên cùng benchmark snapshot;
6. xác minh đủ 5 metric delta;
7. xác minh input SHA-256;
8. xác minh report có `reproducibleInputs=true`;
9. xác minh `productionMutationPerformed=false`;
10. benchmark mismatch bị từ chối;
11. production vẫn là production;
12. candidate vẫn là candidate.
