# v2.6.5 — Cổng xét duyệt mô hình

Bản này thêm Promotion Gate để đánh giá candidate trước khi được xem là đủ điều kiện lên staging.

## Nguyên tắc

Promotion Gate chỉ đưa ra quyết định:

- approved-for-staging
- blocked

Nó không tự đổi stage model và không tự promote production.

## Các gate

### Critical regression

Nếu `criticalRegression=true`:

- luôn fail;
- luôn block promotion;
- không phụ thuộc các metric khác.

### Regression

Candidate phải:

- có regression pass rate >= ngưỡng;
- không thấp hơn production.

### Security

Request phải xác nhận:

`securityPassed=true`

Nếu false, gate bị chặn.

### Lineage

Request phải xác nhận:

`lineagePassed=true`

Nếu false, gate bị chặn.

### Latency

Candidate latency delta so với production không được vượt:

`maximumLatencyIncreaseMilliseconds`

### Cost

Candidate cost delta không được vượt:

`maximumCostIncreasePerCase`

### Resource

Candidate resource ratio được so với baseline 1.0.

Ví dụ:

- 1.00 = ngang production
- 1.10 = tăng 10%
- 1.25 = tăng 25%

Gate yêu cầu phần tăng không vượt `maximumResourceIncreaseRatio`.

## Input

Promotion Gate đọc trực tiếp RegisteredModelComparisonReport của v2.6.4.

Nhờ vậy candidate/production identity và benchmark snapshot đã được cố định từ bước comparison trước.

## Output

PromotionGateDecision lưu:

- comparison report ID;
- candidate model version ID;
- production model version ID;
- family;
- từng check;
- critical flag;
- detail;
- decision;
- eligibleForStaging;
- productionMutationPerformed=false;
- timestamp.

## API

- `GET /api/model-lab/promotion-gates/status`
- `GET /api/model-lab/promotion-gates`
- `GET /api/model-lab/promotion-gates/{gateId}`
- `POST /api/model-lab/promotion-gates/evaluate`

## Audit

Mỗi quyết định đều ghi:

`model-lab.promotion-gate.evaluate`

Audit chứa comparison ID, decision và candidate model ID.

## Safety

Status công bố:

- `criticalRegressionAlwaysBlocks=true`
- `autoPromotionEnabled=false`
- `auditRequired=true`

Gate không:

- đổi model stage;
- đưa candidate lên staging;
- thay production;
- chuyển traffic;
- bỏ qua critical regression.

## Kiểm thử tự động

Workflow `model-lab-v265.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. seed comparison report;
5. tất cả gate đạt → approved-for-staging;
6. productionMutationPerformed vẫn false;
7. criticalRegression=true → luôn blocked;
8. report được lưu lại;
9. status phản ánh đúng approved/blocked counts.
