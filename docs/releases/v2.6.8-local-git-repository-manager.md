# v2.6.8 — Bộ quản lý kho mã nguồn trên máy

Bản này mở rộng Development subsystem với Local Git Repository Service có kiểm soát.

## Mục tiêu

Cho PersonalAI làm việc trực tiếp với Git repository nằm trong workspace mà không mở generic shell.

Các thao tác hỗ trợ:

- status;
- fetch;
- branch list;
- branch create;
- checkout;
- diff;
- log;
- pull --ff-only;
- commit;
- push.

## Workspace boundary

Repository phải nằm bên trong workspace hiện tại.

Service:

1. resolve repository path từ workspace root;
2. chặn path escape;
3. chặn symlink/reparse traversal;
4. dùng `git rev-parse --show-toplevel`;
5. xác minh Git top-level vẫn nằm trong workspace.

Không cho Git operation chạy trên repository ngoài workspace.

## Read operations

Không cần xác nhận:

- status;
- branch list;
- diff;
- log.

Output bị giới hạn để tránh trả log/diff quá lớn.

## Write operations

Các thao tác sau bắt buộc:

`confirmGitWrite=true`

- fetch;
- checkout;
- create branch;
- pull;
- commit;
- push.

Checkout, create branch và pull yêu cầu worktree sạch.

## Pull

Pull luôn chạy:

`git pull --ff-only <remote> <branch>`

Không có merge fallback.

Nếu remote history không fast-forward được thì Git operation fail.

## Commit

Commit không nhận arbitrary shell command.

Request phải chỉ rõ:

- repositoryPath;
- message;
- danh sách paths;
- confirmation.

Service:

1. validate tối đa 50 path;
2. chặn absolute path;
3. chặn path traversal;
4. chặn `.git`;
5. chỉ `git add -- <explicit paths>`;
6. xác minh có staged changes;
7. chạy `git commit -m <message>`.

Commit message chỉ cho một dòng, tối đa 300 ký tự.

## Push

Push chỉ được phép với branch hiện tại:

`git push <remote> <current-branch>`

Không có input force flag.
Không có force-with-lease.
Không có refspec xóa branch.

## Các thao tác cố tình không hỗ trợ

v2.6.8 không cung cấp:

- `git reset`;
- `git reset --hard`;
- `git push --force`;
- `git push --force-with-lease`;
- `git merge`;
- `git rebase`;
- generic Git arguments;
- generic shell;
- cmd /c;
- PowerShell command execution.

## API

### Capabilities

- `GET /api/development/git/capabilities`

### Read

- `GET /api/development/git/status?repositoryPath=...`
- `GET /api/development/git/branches?repositoryPath=...`
- `POST /api/development/git/diff`
- `POST /api/development/git/log`

### Controlled write

- `POST /api/development/git/fetch`
- `POST /api/development/git/checkout`
- `POST /api/development/git/branches`
- `POST /api/development/git/pull`
- `POST /api/development/git/commit`
- `POST /api/development/git/push`

## Development capabilities

Development Agent status giờ công bố:

- git-fetch;
- git-branch;
- git-checkout;
- git-log;
- git-pull-ff-only;
- git-commit;
- git-push.

`GitWriteActionsEnabled=true` có nghĩa là các write action có kiểm soát đã tồn tại.

Nó không có nghĩa arbitrary Git command được bật.

## Audit

Mọi Git write action ghi audit:

- `development.git.fetch`
- `development.git.checkout`
- `development.git.branch-create`
- `development.git.pull`
- `development.git.commit`
- `development.git.push`

Audit không ghi raw source diff hoặc credential.

## Safety status

Local Git capabilities công bố:

- `pullFastForwardOnly=true`;
- `forcePushEnabled=false`;
- `resetEnabled=false`;
- `genericShellEnabled=false`.
