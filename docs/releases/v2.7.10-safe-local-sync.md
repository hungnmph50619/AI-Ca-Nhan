# v2.7.10 — Tự đồng bộ code về máy

Bản này bổ sung Safe Local Sync cho DevelopmentRun stage=local-sync.

## Mục tiêu

Sau khi Pull Request đã merge:

fetch
→ status
→ nếu dirty thì defer
→ checkout main/master
→ pull --ff-only
→ completed

Không reset, không clean và không ghi đè thay đổi người dùng.

## Prerequisite

Local sync chỉ chạy khi:

- ConfirmSync=true;
- DevelopmentRun active;
- stage=local-sync;
- run có MergePolicyReportId;
- merge policy report thuộc đúng run;
- report.Merged=true.

Nếu PR chưa merge thì sync bị từ chối.

## Fetch trước status

Service cho phép fetch trước khi kiểm tra dirty tree vì fetch chỉ cập nhật remote refs và không thay đổi working tree.

Sau fetch, service gọi Git status.

Nếu có staged/unstaged/untracked change:

- State=deferred-dirty-tree;
- DirtyTreeDetected=true;
- CheckoutPerformed=false;
- Synced=false;
- DeferredReason=working-tree-dirty.

Không checkout và không pull.

## Dirty-tree detection

LocalGitRepositoryService trả:

`git status --short --branch --untracked-files=normal`

Safe Local Sync bỏ qua dòng branch header bắt đầu bằng:

`## `

Bất kỳ dòng status khác đều được coi là user/local dirty work.

## Clean sync

Khi tree sạch:

1. xác định branch hiện tại;
2. nếu chưa ở base branch thì checkout main/master;
3. pull bằng LocalGitRepositoryService;
4. LocalGitRepositoryService luôn dùng `git pull --ff-only`;
5. xác minh branch sau sync.

BaseBranch chỉ được:

- main
- master.

## Deferred không phải failure phá dữ liệu

Dirty tree không bị reset/clean/stash tự động.

Report được persist để orchestration biết sync đang chờ user/local work được xử lý.

Có thể retry Local Sync sau khi working tree trở lại clean.

## Report

DevelopmentLocalSyncReport lưu:

- report ID;
- workspace ID;
- DevelopmentRun ID;
- repository;
- remote;
- base branch;
- branch before;
- branch after;
- state;
- fetch succeeded;
- dirty detected;
- checkout performed;
- pull fast-forward-only;
- synced;
- deferred reason;
- timestamp.

Các state:

- synced;
- deferred-dirty-tree;
- failed.

## DevelopmentRun completion gate

AdvanceDevelopmentRunRequest có thêm:

`LocalSyncReportId`

Khi current stage=local-sync:

1. LocalSyncReportId bắt buộc;
2. report phải tồn tại;
3. report phải thuộc đúng DevelopmentRun;
4. report.Synced=true;
5. DirtyTreeDetected=false;
6. State=synced.

Deferred/failed report không thể làm DevelopmentRun completed.

Chỉ successful local sync mới cho:

local-sync → completed

## API

- `GET /api/development/local-sync/status`
- `GET /api/development/local-sync/reports`
- `GET /api/development/local-sync/reports/{reportId}`
- `POST /api/development/local-sync/run`

## Status

Status công bố:

- dirtyTreeDefersSync=true;
- pullFastForwardOnly=true;
- resetEnabled=false;
- cleanEnabled=false.

## Audit

Mỗi attempt ghi:

`development.local-sync`

Audit chỉ lưu metadata:

- report;
- state;
- dirty;
- fetch;
- checkout;
- ff-only;
- synced.

Không ghi source content.

## Capability

Development Agent công bố:

`safe-local-sync`

## Safety

v2.7.10 không:

- reset dirty tree;
- clean untracked files;
- stash user work tự động;
- checkout khi tree dirty;
- pull khi tree dirty;
- dùng non-ff pull;
- hoàn tất DevelopmentRun bằng deferred report.

## Kiểm thử tự động

Workflow `development-v2710.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. tạo bare remote và local repo;
5. local checkout experiment branch;
6. tạo user dirty change;
7. remote main có commit mới mô phỏng merged PR;
8. DevelopmentRun được đặt ở local-sync với merged policy report;
9. sync attempt 1 fetch thành công;
10. dirty tree được phát hiện;
11. sync bị defer;
12. hash dirty file không đổi;
13. user change vẫn còn;
14. branch vẫn experiment;
15. merged file chưa xuất hiện local;
16. deferred report không thể complete run;
17. sau khi user change được xử lý, retry sync;
18. checkout main;
19. pull --ff-only;
20. merged file xuất hiện;
21. local HEAD bằng merged remote SHA;
22. successful report cho phép local-sync → completed;
23. status có 1 deferred + 1 synced report;
24. capability safe-local-sync được công bố.
