# v2.7.3 — AI tự viết và sửa code

Bản này nâng cấp SelfCodingService để sửa source code thật trong isolated experiment worktree, gắn với DevelopmentRun stage=cod­ing.

## Coding gate

Self Coding chỉ chạy khi:

- có DevelopmentRunId;
- DevelopmentRun tồn tại trong workspace hiện tại;
- run status=active;
- run stage=coding;
- run branch khớp experiment branch;
- repository khớp;
- experiment branch có tiền tố experiment/*;
- proposal yêu cầu human approval;
- xác nhận branch/worktree và file change đã có.

Nếu run chưa ở coding, request bị chặn.

## Worktree isolation

SelfCoding không còn checkout/sửa trực tiếp working tree chính.

Luồng:

DevelopmentRun(coding)
→ acquire branch lease
→ tìm isolated worktree của experiment branch
→ nếu chưa có thì tạo .personalai-worktrees/selfcoding-{runId}
→ ghi file trong worktree
→ audit từng edit
→ release lease

Nếu experiment branch đang được checkout ở main worktree, SelfCoding từ chối chạy thay vì sửa trực tiếp.

## File safety

Mỗi run tối đa 8 edit.

Mỗi file tối đa 200,000 ký tự.

Chỉ cho:

- create
- overwrite

Không cho append.

Overwrite bắt buộc có expectedSha256.

Path bị chặn nếu:

- absolute;
- traversal ..;
- chạm .git;
- chạm .personalai-worktrees từ bên trong edit;
- trùng path trong cùng request.

## Audit

Mỗi file edit ghi:

`self-improvement.self-coding.write`

với:

- DevelopmentRun ID;
- branch;
- worktree path;
- resulting SHA-256.

Không ghi source content vào audit.

Khi hoàn tất:

`self-improvement.self-coding.complete`

ghi:

- experiment ID;
- worktree;
- số file;
- main-modified:false.

## Result

SelfCodingResult v2.7.3 có thêm:

- developmentRunId;
- worktreePath;
- mainWorktreeModified=false;
- auditPerEdit=true.

SelfCoding vẫn không tự:

- commit;
- push;
- merge;
- advance DevelopmentRun sang testing.

Các bước đó vẫn đi qua orchestration riêng.

## Branch lease

Trước khi sửa, SelfCoding lấy branch lease:

`self-coding:{developmentRunId}`

TTL tối đa 3600 giây.

Writer khác giữ lease xung đột sẽ chặn coding.

Release được thực hiện best-effort sau run; nếu release lỗi thì expiry vẫn giải phóng lease.

## Capability

Development Agent công bố:

`self-coding-worktree`

## Safety

v2.7.3 không:

- sửa main/master trực tiếp;
- checkout experiment branch vào main worktree;
- sửa source khi DevelopmentRun chưa ở coding;
- bypass diagnosis gate của improvement-driven run;
- force reset;
- tự commit;
- tự push;
- tự merge;
- ghi source content vào audit.

## Kiểm thử tự động

Workflow `development-v273.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. tạo Git repo thật ở main;
5. tạo dirty user change trong main;
6. tạo DevelopmentRun ở analysis;
7. SelfCoding trước coding bị chặn;
8. advance run sang coding;
9. SelfCoding tạo experiment worktree;
10. file agent chỉ xuất hiện trong worktree;
11. file agent không xuất hiện trong main;
12. hash file dirty main không đổi;
13. main vẫn checkout branch main;
14. result báo mainWorktreeModified=false;
15. commit/push/merge=false;
16. audit từng edit tồn tại;
17. completion audit tồn tại;
18. DevelopmentRun vẫn ở coding sau SelfCoding.
