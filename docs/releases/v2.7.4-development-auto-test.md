# v2.7.4 — AI tự build và test

Bản này bổ sung DevelopmentAutoTestService cho DevelopmentRun stage=testing.

## Mục tiêu

Tự động chạy trên isolated experiment worktree:

- restore;
- build;
- unit test;
- integration test nếu có target riêng;
- regression evaluation.

Mọi report được persist theo workspace.

Failure output được redact trước khi lưu.

## Testing gate

Development auto test chỉ chạy khi:

- ConfirmExecution=true;
- DevelopmentRun tồn tại;
- run thuộc workspace hiện tại;
- run status=active;
- run stage=testing;
- branch là experiment/*;
- có isolated worktree cho branch đó.

Không chạy test trên main worktree.

## Các phase

### restore

Chạy:

`dotnet restore`

trên target trong isolated worktree.

Nếu fail, report dừng tại phase này.

### build

Chạy:

`dotnet build --no-restore -c Release`

Nếu fail, các phase tiếp theo không chạy.

### unit

Chạy `dotnet test` trên UnitTestTargetPath.

Nếu không cấu hình riêng, dùng DotnetTargetPath.

### integration

Chỉ chạy khi IntegrationTestTargetPath được cấu hình.

Nếu không có target riêng:

`status=skipped`

Bản này không giả vờ đã chạy integration test khi repo chưa có suite riêng.

### regression

Đọc regression dataset hiện có và chạy các case có evaluator hỗ trợ.

Case category chưa có evaluator được ghi skipped.

Regression phase fail nếu có ít nhất một case fail.

## Failure log

Failure log tối đa 32,000 ký tự.

Trước khi persist, service redact các pattern phổ biến:

- GitHub token;
- github_pat;
- OpenAI-style secret;
- AWS access key;
- Authorization header;
- Bearer credential.

Report không persist raw output nếu phase thành công.

## Report

Mỗi DevelopmentTestReport lưu:

- report ID;
- workspace ID;
- DevelopmentRun ID;
- repository;
- branch;
- worktree path;
- target path;
- danh sách phase;
- overall success;
- startedAt;
- completedAt.

Mỗi phase lưu:

- phase name;
- status;
- exit code;
- timeout;
- duration;
- failure log đã redact;
- truncation flag;
- regression counters nếu có.

## Persistence

Report được lưu theo workspace tại:

`Development/TestReports/development-test-reports-{workspace}.json`

Write qua temp file rồi replace.

## API

- `GET /api/development/tests/status`
- `GET /api/development/tests/reports`
- `GET /api/development/tests/reports/{reportId}`
- `POST /api/development/tests/run`

## Status

Status công bố:

- reportsPersisted=true;
- failureLogsPersisted=true;
- failureLogsRedacted=true;
- worktreeOnly=true.

## Audit

Mỗi run hoàn tất ghi:

`development.auto-test.complete`

Audit chỉ lưu:

- DevelopmentRun ID;
- report ID;
- success/failure;
- số phase;
- worktree path.

Không ghi raw failure output vào audit.

## Capability

Development Agent công bố:

`development-auto-test`

## Tương thích

AutoTestService cũ của Self Improvement vẫn được giữ để không phá API cũ.

v2.7.4 thêm DevelopmentAutoTestService riêng vì DevelopmentRun mới có thứ tự:

coding → testing → review

trong khi AutoTestService cũ giả định review xảy ra trước test.

## Safety

v2.7.4 không:

- test trên main worktree;
- tự commit;
- tự push;
- tự merge;
- tự advance DevelopmentRun sang review;
- giả vờ integration test đã chạy nếu chưa có integration target;
- persist plaintext credential pattern trong failure log.

## Kiểm thử tự động

Workflow `development-v274.yml` kiểm tra:

1. restore project chính;
2. build project chính;
3. dotnet test project chính;
4. tạo Git repo test;
5. tạo DevelopmentRun và đưa tới testing;
6. tạo isolated experiment worktree;
7. chạy restore/build/unit/regression thành công;
8. integration không cấu hình → skipped;
9. persist success report;
10. tạo build failure có chuỗi giống credential;
11. failure report được persist;
12. secret bị thay bằng [REDACTED];
13. persisted JSON không chứa plaintext secret;
14. restart app;
15. cả success report và failure report vẫn đọc lại được;
16. capability development-auto-test được công bố.
