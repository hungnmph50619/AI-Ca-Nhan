# v2.7.5 — AI review code riêng

Bản này bổ sung DevelopmentReviewService cho DevelopmentRun stage=review.

## Mục tiêu

Reviewer phải độc lập với coding agent và kiểm tra:

- correctness;
- architecture;
- regression.

Coding agent không được tự review/approve code của chính mình.

## Review gate

Development review chỉ chạy khi:

- ConfirmReview=true;
- ConfirmExternalReviewer=true;
- DevelopmentRun tồn tại;
- run thuộc workspace hiện tại;
- run status=active;
- run stage=review;
- test report thuộc đúng DevelopmentRun;
- test report thuộc đúng branch/worktree;
- reviewerId khác codingAgentId;
- reviewerId bắt buộc là `quality.reviewer`.

Nếu codingAgentId == reviewerId:

HTTP 400

và review không chạy.

## Reviewer độc lập

Reviewer runtime dùng:

`ReviewerFrameworkAgent.AgentId = quality.reviewer`

Review material chỉ gồm:

- DevelopmentRun ID;
- branch;
- DevelopmentTestReport ID;
- test pass/fail;
- working-tree diff từ isolated worktree.

Reviewer không được dùng memory/task/life context.

## Regression check

Review luôn đọc DevelopmentTestReport của v2.7.4.

Nếu test report failed:

`regression = failed`

và review không thể approved.

## Correctness check

Correctness pass khi:

- ReviewerReport không có finding;
- evidence excerpts được reviewer parser xác minh.

Nếu có finding hoặc evidence invalid:

`correctness = changes-required`

## Architecture check

Architecture check xem các finding có architecture/coupling concern hay không.

Nếu có:

`architecture = changes-required`

## Approval rule

DevelopmentReviewReport chỉ có:

`approved=true`

khi đồng thời:

- testReport.Succeeded=true;
- correctness pass;
- architecture pass;
- reviewer độc lập;
- Reviewer Agent không tự set Approved;
- Reviewer Agent không modify content;
- Reviewer Agent không execute tools;
- Reviewer Agent không dispatch agents.

Điều này giữ reviewer ở vai trò đánh giá, không biến reviewer thành coding/deployment agent.

## Không tự advance state machine

Review report không tự chuyển:

review → security

DevelopmentRun vẫn phải được advance riêng.

Nhờ vậy reviewer không vừa đánh giá vừa tự điều khiển toàn bộ pipeline.

## Persistence

Review report được lưu theo workspace tại:

`Development/Reviews/development-review-reports-{workspace}.json`

Mỗi report lưu:

- report ID;
- DevelopmentRun ID;
- TestReport ID;
- repository;
- branch;
- worktree;
- codingAgentId;
- reviewerId;
- correctness/architecture/regression checks;
- status;
- approved;
- independentReviewer=true;
- createdAt.

## API

- `GET /api/development/reviews/status`
- `GET /api/development/reviews`
- `GET /api/development/reviews/{reportId}`
- `POST /api/development/reviews/run`

## Status

Status công bố:

- reportsPersisted=true;
- independentReviewerRequired=true;
- developerSelfApprovalAllowed=false;
- requiredChecks=[correctness, architecture, regression].

## Audit

Review hoàn tất ghi:

`development.review.complete`

Audit lưu:

- DevelopmentRun ID;
- review report ID;
- coding agent;
- reviewer;
- approval result;
- số findings.

Không ghi full diff/source vào audit.

## Capability

Development Agent công bố:

`independent-code-review`

## Safety

v2.7.5 không:

- cho coding agent tự review;
- cho arbitrary reviewer ID approve;
- review khi run chưa ở stage review;
- bỏ qua failed test report;
- cho reviewer modify source;
- cho reviewer execute tools;
- cho reviewer dispatch agents;
- tự advance DevelopmentRun;
- tự commit/push/merge.

## Kiểm thử tự động

Workflow `development-v275.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. status version 2.7.5;
5. independentReviewerRequired=true;
6. developerSelfApprovalAllowed=false;
7. đủ correctness/architecture/regression;
8. đưa DevelopmentRun đến review stage;
9. codingAgentId == reviewerId bị HTTP 400;
10. reviewer khác quality.reviewer bị chặn;
11. thiếu external reviewer confirmation bị chặn;
12. source service bắt buộc ReviewerFrameworkAgent.AgentId;
13. source service dùng testReport.Succeeded;
14. capability independent-code-review được công bố.

CI không giả lập một AI provider đã review thành công khi môi trường GitHub Actions chưa cấu hình provider thật.
