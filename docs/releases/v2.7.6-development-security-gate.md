# v2.7.6 — AI kiểm tra bảo mật

Bản này bổ sung Development Security Gate cho DevelopmentRun stage=security.

## Mục tiêu

Security Agent kiểm tra source change trong isolated experiment worktree cho các nhóm:

- secret leakage;
- permission bypass;
- injection;
- path traversal;
- dangerous execution.

Bất kỳ high-risk finding nào đều chặn promotion từ:

security → benchmark

## Security material

Service không chỉ đọc git diff.

Nó thu thập:

- tracked working-tree diff;
- git status;
- nội dung các file untracked mới.

Điều này tránh bỏ sót rủi ro trong file mới chưa được git track.

Giới hạn:

- tổng material tối đa 32,000 ký tự;
- chunk tối đa 3,600 ký tự;
- tối đa 20 untracked files;
- tối đa 8,000 ký tự mỗi untracked file.

## Security Agent

DevelopmentSecurityService gọi:

`security.security-reviewer`

Agent chạy local deterministic patterns, không dùng external AI provider.

Agent không echo source/token trong finding.

## Rule coverage

### Secret leakage

Rule:

`credential-material`

Tìm dấu hiệu token, password, API key hoặc private key.

### Permission bypass

Rule:

`permission-bypass`

Tìm dấu hiệu như chmod 777, --no-verify, disable audit/firewall hoặc grant all privileges.

### Injection

Rule mới:

`command-injection`

Tìm dấu hiệu:

- eval/exec;
- shell -c;
- cmd /c;
- PowerShell command/encodedcommand;
- UseShellExecute=true;
- Runtime.exec.

### Path traversal

Rule mới:

`path-traversal`

Tìm ../ hoặc ..\\ xuất hiện gần file/path operation mà chưa thấy boundary validation.

### Dangerous execution

Nhóm này ánh xạ các rule:

- destructive-action;
- remote-code-execution;
- external-transfer.

## Review prerequisite

Security review chỉ chạy khi:

- ConfirmSecurityReview=true;
- DevelopmentRun đang active;
- stage=security;
- branch là experiment/*;
- có DevelopmentReviewReport đúng run;
- review report đã approved;
- worktree là isolated agent worktree.

## Report

DevelopmentSecurityReport lưu:

- report ID;
- workspace ID;
- DevelopmentRun ID;
- ReviewReport ID;
- repository;
- branch;
- worktree;
- findings;
- checked categories;
- HighRiskFound;
- PromotionAllowed;
- CreatedAt.

Report không lưu raw source material.

Finding chỉ lưu rule/category/severity/title/detail cố định từ security rules.

## Promotion gate

AdvanceDevelopmentRunRequest có thêm:

`securityReportId`

Khi current stage=security:

1. securityReportId bắt buộc;
2. report phải tồn tại;
3. report phải thuộc đúng DevelopmentRun;
4. HighRiskFound phải=false;
5. PromotionAllowed phải=true.

Nếu có high-risk:

HTTP 409 Conflict

và run vẫn ở security.

Report sạch mới được chuyển:

security → benchmark

DevelopmentRun persist SecurityReportId đã dùng để promotion.

## Persistence

Report được lưu theo workspace:

`Development/SecurityReports/development-security-reports-{workspace}.json`

Status công bố:

## Audit

Security run hoàn tất ghi:

`development.security.complete`

Audit lưu:

- DevelopmentRun ID;
- report ID;
- số findings;
- high-risk flag;
- promotion-allowed flag.

Không ghi raw diff/source/token vào audit.
