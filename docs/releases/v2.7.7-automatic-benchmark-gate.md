# v2.7.7 — Cổng benchmark tự động

Bản này bổ sung Automatic Benchmark Gate cho DevelopmentRun stage=benchmark.

## Mục tiêu

Chạy sáu regression gate bắt buộc:

- RAG;
- tool;
- task;
- agent;
- performance;
- resource.

Benchmark report fail sẽ chặn:

benchmark → push

## Regression dataset

Service đọc các regression case đang bật từ IRegressionDatasetStore.

Các case có evaluator được chạy qua IEvaluationEngine.

Các metric chuẩn dùng:

- rag.accuracy;
- tool.success_rate;
- task.success_rate.

Nếu một metric bắt buộc không tồn tại trong regression results:

gate tương ứng fail.

Không coi thiếu dữ liệu là pass.

## RAG/tool/task gates

Mỗi gate nhận threshold explicit trong request.

Mặc định:

- MinimumRagScore = 0.8
- MinimumToolScore = 0.8
- MinimumTaskScore = 0.8

Observed value là average của metric tương ứng trên các evaluation result có metric đó.

## Agent gate

Agent gate dùng AgentBenchmarkService và regression category:

`agent.benchmark`

Agent benchmark là gate bắt buộc.

Để chạy phải:

- IncludeAgentBenchmark=true;
- ConfirmExternalExecution=true.

Nếu agent benchmark không được yêu cầu hoặc không có case:

agent gate fail.

Agent gate kiểm tra:

- pass rate >= MinimumAgentPassRate;
- average latency <= MaximumAverageAgentLatencyMs.

Mặc định:

- MinimumAgentPassRate = 0.8
- MaximumAverageAgentLatencyMs = 5000.

## Performance gate

Performance gate đo tổng thời gian DevelopmentBenchmarkService chạy.

Mặc định:

`MaximumDurationMs = 30000`

Nếu vượt ngưỡng thì gate fail.

## Resource gate

Resource gate đo process working set trước/sau benchmark và dùng giá trị lớn hơn.

Mặc định:

`MaximumWorkingSetBytes = 1 GiB`

Nếu vượt ngưỡng thì gate fail.

Đây là process-level resource guard của v2.7.7, chưa phải profiler CPU/GPU chi tiết.

## Report

DevelopmentBenchmarkReport lưu:

- report ID;
- workspace ID;
- DevelopmentRun ID;
- sáu gate result;
- evaluated case count;
- failed case count;
- overall Passed;
- duration;
- working set;
- startedAt;
- completedAt.

Mỗi gate lưu:

- gate;
- passed;
- observed;
- threshold;
- detail.

## Fail-closed

Các tình huống sau không được coi là pass:

- thiếu rag.accuracy;
- thiếu tool.success_rate;
- thiếu task.success_rate;
- agent benchmark chưa chạy;
- không có agent benchmark case;
- agent pass rate thấp;
- agent latency vượt ngưỡng;
- benchmark quá thời gian;
- working set vượt ngưỡng.

## Promotion gate

AdvanceDevelopmentRunRequest có thêm:

`benchmarkReportId`

Khi current stage=benchmark:

1. benchmarkReportId là bắt buộc;
2. report phải tồn tại;
3. report phải thuộc đúng DevelopmentRun;
4. report.Passed phải=true.

Nếu report fail:

HTTP 409 Conflict

và DevelopmentRun vẫn ở benchmark.

Nếu pass:

benchmark → push

và BenchmarkReportId được persist vào DevelopmentRun.

## Persistence

Benchmark report được lưu theo workspace tại:

`Development/Benchmarks/development-benchmark-reports-{workspace}.json`

BenchmarkReportStore được tách khỏi DevelopmentBenchmarkService để tránh circular dependency với DevelopmentRunService.

## API

- `GET /api/development/benchmarks/status`
- `GET /api/development/benchmarks/reports`
- `GET /api/development/benchmarks/reports/{reportId}`
- `POST /api/development/benchmarks/run`

## Status

Status công bố:

- reportsPersisted=true;
- failedBenchmarkBlocksContinuation=true;
- requiredGates gồm đủ 6 gate roadmap.

## Audit

Mỗi benchmark hoàn tất ghi:

`development.benchmark.complete`

Audit lưu:

- DevelopmentRun ID;
- report ID;
- pass/fail;
- số gate fail;
- số evaluation case.

## Capability

Development Agent công bố:

`automatic-benchmark-gate`

## Safety

v2.7.7 không:

- coi thiếu benchmark metric là pass;
- bỏ qua agent gate;
- tự push;
- tự merge;
- tự advance DevelopmentRun;
- tự sửa source khi benchmark fail;
- giả lập benchmark report thành công.

## Kiểm thử tự động

Workflow `development-v277.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. status version 2.7.7;
5. required gates đủ 6 nhóm;
6. đưa DevelopmentRun tới benchmark;
7. chạy benchmark trong môi trường thiếu metric/agent;
8. RAG/tool/task/agent gate fail;
9. overall report fail;
10. benchmark → push bị HTTP 409;
11. seed pass report để kiểm tra riêng promotion contract;
12. pass report cho phép benchmark → push;
13. BenchmarkReportId được persist;
14. capability automatic-benchmark-gate được công bố.
