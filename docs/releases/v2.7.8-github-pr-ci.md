# v2.7.8 — AI tự push GitHub, tạo PR và theo dõi CI

Bản này nối DevelopmentRun stage push/ci với Git + GitHub Pull Request + CI Monitor.

## Mục tiêu

Pipeline:

benchmark
→ push experiment branch
→ tạo/reuse Pull Request
→ ci
→ đọc CI state/failure excerpt
→ repair tối đa 3 vòng
→ CI success
→ merge-policy

## Chặn push main/master

LocalGitRepositoryService từ v2.7.8 chặn trực tiếp:

- main
- master

ở chính PushAsync.

Không chỉ DevelopmentGitHubService mà mọi caller của Local Git push đều bị chặn nếu branch hiện tại là main/master.

Thông báo yêu cầu dùng experiment branch và Pull Request.

## GitHub automation gate

DevelopmentGitHubService chỉ chạy khi:

- ConfirmPush=true;
- ConfirmCreatePullRequest=true;
- DevelopmentRun active;
- stage=push;
- branch bắt đầu bằng experiment/;
- branch không phải main/master;
- isolated worktree tồn tại;
- Git credential là https-token;
- BaseBranch là main hoặc master.

## Push

Push dùng LocalGitRepositoryService:

`git push <remote> <experiment-branch>`

Không có force flag.

Credential lấy từ GitCredentialService đã mã hóa từ v2.6.11.

Token không được persist vào GitHub report hoặc audit.

## Pull Request

GitHub API base mặc định:

`https://api.github.com`

Có thể override Development:GitHubApiBaseUrl để test.

Trước khi create, service gọi danh sách PR mở theo:

- repository;
- head owner:experiment-branch;
- base main/master.

Nếu đã có PR phù hợp thì reuse.

Nếu chưa có thì POST tạo PR mới.

PR response chỉ persist:

- PR number;
- html_url.

## DevelopmentGitHubReport

Report lưu:

- report ID;
- workspace ID;
- DevelopmentRun ID;
- repository owner/name;
- experiment branch;
- base branch;
- isolated worktree path;
- remote;
- pushed;
- PR created;
- PR number;
- PR URL;
- linked CI run ID;
- CI state/conclusion;
- repair attempts;
- maximum repair attempts;
- timestamps.

## Push → CI gate

AdvanceDevelopmentRunRequest có thêm:

`gitHubReportId`

Khi current stage=push:

1. GitHubReportId bắt buộc;
2. report phải tồn tại;
3. report phải thuộc đúng DevelopmentRun;
4. Pushed=true;
5. PullRequestCreated=true.

Chỉ khi đủ điều kiện:

push → ci

## CI correlation

DevelopmentGitHubService dùng CiMonitor từ v2.6.13.

CI được match bằng:

- repository;
- ref == experiment branch.

Refresh API cập nhật GitHub report với:

- CiRunId;
- state;
- conclusion;
- repairAttempts.

Nếu CI record có failureLogExcerpt thì API trả excerpt đã persist/redact từ CiMonitor.

v2.7.8 chưa tự tải full GitHub Actions ZIP log:

`FullGitHubLogDownloadEnabled=false`

## Finite repair

Repair API dùng trực tiếp CiMonitor.RequestRepair.

Hard limit:

`3`

Luồng:

attempt 1 → allowed  
attempt 2 → allowed  
attempt 3 → allowed  
attempt 4 → HTTP 409

Không có retry vô hạn.

## CI → merge-policy gate

Khi DevelopmentRun đang ở ci:

- CiRunId bắt buộc;
- CI record phải tồn tại;
- state phải completed;
- conclusion phải success.

Nếu CI failure/pending/cancelled/timed-out:

ci → merge-policy bị chặn.

## API

- `GET /api/development/github/status`
- `GET /api/development/github/reports`
- `GET /api/development/github/reports/{reportId}`
- `POST /api/development/github/run`
- `POST /api/development/github/reports/{reportId}/ci/refresh`
- `POST /api/development/github/reports/{reportId}/ci/repair`

## Status

Status công bố:

- directMainPushAllowed=false;
- pullRequestRequired=true;
- maximumCiRepairAttempts=3;
- ciFailureExcerptReadable=true;
- fullGitHubLogDownloadEnabled=false.

## Persistence

GitHub automation report được lưu theo workspace tại:

`Development/GitHub/development-github-reports-{workspace}.json`

Token không được lưu trong report.

## Audit

Các action:

- `development.github.push-pr`
- `development.github.ci-repair`

Audit chỉ lưu repository/branch/base/PR/attempt metadata và ghi secret:redacted.

## Capability

Development Agent công bố:

`github-pull-request-ci`

## Safety

v2.7.8 không:

- push main/master;
- force push;
- tạo PR từ branch không phải experiment/*;
- tạo PR về base tùy ý ngoài main/master;
- persist GitHub token trong report/audit;
- retry CI quá 3 vòng;
- cho CI fail đi sang merge-policy;
- tự merge Pull Request.
