# v2.7.9 — Bộ luật quyết định có được merge hay không

Bản này bổ sung Development Merge Policy cho DevelopmentRun stage=merge-policy.

## Mục tiêu

Chỉ auto-merge low-risk khi toàn bộ gate bắt buộc đã đạt:

- CI;
- independent review;
- security;
- benchmark;
- Pull Request.

High-risk không bao giờ được auto-merge.

## Risk levels

Hỗ trợ:

- low
- medium
- high

Chỉ `low` có thể:

`AutomaticMergeEligible=true`

Medium/high luôn:

`RequiresUserConfirmation=true`

và chỉ merge khi request có xác nhận riêng:

`ConfirmNonLowRiskMerge=true`

Riêng high-risk, `AllowAutomaticMerge=true` không có tác dụng nếu chưa có user confirmation.

## Required checks

### Review

DevelopmentReviewReport phải:

- thuộc đúng DevelopmentRun;
- Approved=true.

### Security

DevelopmentSecurityReport phải:

- thuộc đúng DevelopmentRun;
- PromotionAllowed=true;
- HighRiskFound=false.

Security high-risk finding vẫn là hard block từ v2.7.6, không thể override qua merge policy.

### Benchmark

DevelopmentBenchmarkReport phải:

- thuộc đúng DevelopmentRun;
- Passed=true.

### CI

CI run phải:

- state=completed;
- conclusion=success.

### Pull Request

DevelopmentGitHubReport phải:

- thuộc đúng DevelopmentRun;
- Pushed=true;
- PullRequestCreated=true;
- branch khớp experiment branch của run.

## Auto-merge

Low-risk chỉ auto-merge khi:

- tất cả required checks pass;
- AllowAutomaticMerge=true.

Merge gọi GitHub API:

`PUT /repos/{owner}/{repo}/pulls/{number}/merge`

với:

`merge_method=squash`

Token được resolve từ encrypted GitCredentialService và chỉ đi trong Authorization header.

Token không được persist trong merge-policy report hoặc audit.

## Non-low-risk merge

Medium/high-risk không bao giờ dùng automatic path.

Nếu tất cả gate pass nhưng chưa có confirmation:

- Decision=requires-user-confirmation;
- MergeAttempted=false;
- Merged=false.

Sau xác nhận riêng, policy mới được phép gọi merge API.

## Decision states

Report dùng các decision:

- blocked
- ready-for-auto-merge
- requires-user-confirmation
- merged

## DevelopmentRun gate

AdvanceDevelopmentRunRequest có thêm:

`MergePolicyReportId`

Khi current stage=merge-policy:

1. MergePolicyReportId bắt buộc;
2. report phải tồn tại;
3. report phải thuộc đúng DevelopmentRun;
4. report.Merged phải=true.

Report chỉ ở trạng thái ready/requires-user-confirmation không mở được local-sync.

Chỉ merge thật thành công mới cho:

merge-policy → local-sync

## Persistence

Report được lưu theo workspace tại:

`Development/MergePolicy/development-merge-policy-{workspace}.json`

Report lưu:

- DevelopmentRun ID;
- GitHub report ID;
- risk level/evidence;
- từng required check;
- all-checks-passed;
- auto-merge eligibility;
- user-confirmation requirement;
- merge attempted;
- merged;
- decision;
- merge commit SHA;
- timestamp.

## API

- `GET /api/development/merge-policy/status`
- `GET /api/development/merge-policy/reports`
- `GET /api/development/merge-policy/reports/{reportId}`
- `POST /api/development/merge-policy/evaluate`

## Status

Status công bố:

- lowRiskAutoMergeEnabled=true;
- highRiskAutoMergeAllowed=false;
- highRiskRequiresUserConfirmation=true;
- requiredChecks=[ci, review, security, benchmark, pull-request].

## Audit

Mỗi evaluation ghi:

`development.merge-policy.evaluate`

Audit lưu:

- DevelopmentRun ID;
- policy report ID;
- risk;
- all-pass;
- auto eligibility;
- requires-user;
- merged.

Không ghi token.

## Capability

Development Agent công bố:

`merge-policy`

## Safety

v2.7.9 không:

- auto-merge medium/high-risk;
- merge khi CI fail;
- merge khi review chưa approved;
- merge khi security high-risk;
- merge khi benchmark fail;
- merge PR của DevelopmentRun khác;
- cho state machine đi local-sync trước khi merge thật;
- persist token trong report/audit.

## Kiểm thử tự động

Workflow `development-v279.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. status version 2.7.9;
5. low-risk auto merge enabled;
6. high-risk auto merge disabled;
7. high-risk requires user confirmation;
8. seed review/security/benchmark/GitHub/CI pass cho cùng run;
9. đưa DevelopmentRun đến merge-policy;
10. evaluate high-risk với AllowAutomaticMerge=true;
11. high-risk vẫn requires-user-confirmation;
12. merge API chưa được gọi;
13. high-risk report không mở được local-sync;
14. evaluate low-risk với đủ gate pass;
15. merge API được gọi;
16. report Merged=true;
17. merge commit SHA được lưu;
18. merge-policy → local-sync thành công;
19. MergePolicyReportId được persist;
20. policy report không chứa plaintext token;
21. capability merge-policy được công bố.
