# v2.8.0 — Trung tâm AI cá nhân

Bản này tạo Device Hub cơ bản để PersonalAI có một nơi thống nhất theo dõi trạng thái PC, laptop, Android và thiết bị khác.

## Mục tiêu

Hub v2.8.0 tập trung vào:

- device presence;
- connection status;
- last-seen;
- persistence theo workspace;
- reconciliation với Android Companion đã pair.

Bản này không mở capability execution và không cấp quyền thiết bị.

## Phạm vi roadmap

v2.8.0 cố ý chưa triển khai các phần thuộc version sau:

- public key/trust level/device identity đầy đủ → v2.8.1;
- pairing protocol mới → v2.8.2;
- capability registry + permission → v2.8.3;
- task routing → v2.8.4;
- distributed agents → v2.8.5.

## Device types

Hub nhận các type:

- pc;
- laptop;
- android;
- other.

Android không được đăng ký bằng local admin API.

Android phải đi qua Companion pairing hiện có trước, sau đó Device Hub chỉ quan sát/tracking thiết bị đã được pair.

## Device state

Mỗi DeviceHubDevice lưu:

- ID của hub record;
- workspace ID;
- name;
- device type;
- source;
- optional CompanionDeviceId;
- connection status;
- PermissionsGranted;
- RemoteExecutionEnabled;
- CreatedAt;
- LastSeenAt;
- UpdatedAt.

## Connection status

Các trạng thái:

- online;
- offline;
- unknown.

Online window:

`5 phút`

Android:

- last-seen lấy từ Companion;
- heartbeat qua authenticated Companion token;
- quá online window thì offline.

PC/laptop/other local-admin device:

- mới register → unknown;
- local admin confirmed heartbeat → online;
- quá online window → offline.

## Không tự cấp quyền

Đây là safety invariant của v2.8.0:

`PermissionsGranted=false`

và:

`RemoteExecutionEnabled=false`

cho mọi DeviceHubDevice.

Service cũng công bố:

- AutomaticPermissionGrantEnabled=false;
- RemoteExecutionEnabled=false.

Heartbeat, register hoặc Companion reconciliation không được thay đổi hai giá trị này thành true.

## Local device registration

Local admin có thể register:

- pc;
- laptop;
- other.

Request yêu cầu:

`ConfirmRegister=true`

Không confirmation thì bị từ chối.

Duplicate cùng source/name/type được trả lại record cũ thay vì tạo duplicate.

Hard limit:

`32 devices/workspace`

## Local heartbeat

Local admin heartbeat yêu cầu:

`ConfirmHeartbeat=true`

Heartbeat chỉ cập nhật:

- ConnectionStatus;
- LastSeenAt;
- UpdatedAt.

Nó không cấp permission.

## Android Companion reconciliation

Device Hub đọc danh sách Android Companion đã pair.

Mỗi paired device được map vào hub bằng:

`CompanionDeviceId`

Nếu Companion device bị revoke, hub reconciliation loại record Companion tương ứng.

Reconciliation không tạo auth token mới và không mở API mutation mới.

## Android heartbeat

Authenticated Android Companion có endpoint:

`POST /api/companion/client/hub/heartbeat`

Authentication vẫn dùng Companion bearer token hiện có.

Device Hub không có auth scheme mới ở v2.8.0.

## API

Local admin:

- `GET /api/device-hub/status`
- `GET /api/device-hub/devices`
- `POST /api/device-hub/admin/devices`
- `POST /api/device-hub/admin/devices/{deviceId}/heartbeat`

Authenticated Companion:

- `POST /api/companion/client/hub/heartbeat`

Companion me response công bố capability:

`device-hub-status`

## Persistence

Mỗi workspace có file:

`device-hub-{workspace}.json`

Write dùng temp-file rồi atomic move.

Nếu JSON state bị hỏng, service fail closed bằng DeviceHubValidationException thay vì giả định danh sách thiết bị rỗng.

## Status contract

DeviceHubStatus công bố:

- Version;
- WorkspaceId;
- TotalDevices;
- OnlineDevices;
- OfflineDevices;
- UnknownDevices;
- DeviceStatePersisted=true;
- CompanionReconciliationEnabled=true;
- AutomaticPermissionGrantEnabled=false;
- RemoteExecutionEnabled=false;
- OnlineWindowMinutes=5;
- SupportedDeviceTypes.

## Audit

Local register ghi:

`device-hub.device.register`

Local heartbeat ghi:

`device-hub.device.heartbeat`

Audit ghi rõ:

- device;
- source/type;
- permissions-granted=false;
- remote-execution=false.

## Safety

v2.8.0 không:

- tự trust device;
- tự cấp permission;
- bật remote tool execution;
- tạo public/private key identity;
- mở task mutation từ device;
- route task sang device;
- cho local admin giả lập Android đã pair;
- lưu Companion token trong Device Hub.

## Kiểm thử tự động

Workflow `device-hub-v280.yml` kiểm tra:

1. restore;
2. build;
3. dotnet test;
4. version 2.8.0;
5. hub ban đầu không có device;
6. AutomaticPermissionGrantEnabled=false;
7. RemoteExecutionEnabled=false;
8. register laptop thiếu confirmation bị chặn;
9. register laptop hợp lệ → status unknown;
10. local admin không được register Android;
11. heartbeat thiếu confirmation bị chặn;
12. confirmed laptop heartbeat → online;
13. tạo Companion pairing ticket;
14. claim Android Companion;
15. authenticated Android heartbeat → online;
16. CompanionDeviceId được liên kết;
17. hub có 2 device;
18. cả hai device permissionsGranted=false;
19. cả hai device remoteExecutionEnabled=false;
20. Companion client công bố device-hub-status;
21. sửa laptop last-seen thành stale;
22. hub tính laptop thành offline;
23. Android vẫn online;
24. persisted JSON vẫn không có device permission=true.
