# v2.8.6 — Đồng bộ ngữ cảnh giữa thiết bị

Mục tiêu của mốc này là chỉ gửi phần context cần thiết cho distributed execution, không đồng bộ toàn bộ trí nhớ vô điều kiện.

## Nguyên tắc

- Context sync gắn với một distributed execution đã có correlation ID.
- Chỉ gửi sang đúng device đã được Task Router chọn.
- Device phải online.
- Capability permission được kiểm tra lại trước khi tạo package.
- Người dùng phải xác nhận bằng `ConfirmSync=true`.
- Full memory sync bị tắt.
- Context được chọn theo query và character budget.
- Caller có thể giới hạn loại context bằng `AllowedKinds`.

## Loại context hỗ trợ

- `memory`
- `task`
- `life-context`

## Giới hạn

- mặc định: 3.000 ký tự;
- tối đa cứng: 6.000 ký tự;
- memory tối đa 1.500 ký tự;
- task tối đa 1.500 ký tự;
- life context tối đa 1.200 ký tự;
- tối đa 4 life-context entries.

## API

- `GET /api/device-context-sync/status`
- `GET /api/device-context-sync`
- `GET /api/device-context-sync/{syncId}`
- `POST /api/tasks/distributed-executions/{correlationId}/context-sync`

## Safety boundary

v2.8.6 không:

- dump toàn bộ memory;
- tự sync khi chưa xác nhận;
- sync tới device khác route;
- sync tới device offline;
- bỏ qua capability permission;
- tự bật loại context ngoài whitelist;
- vượt character budget.

## Kiểm thử tự động

Workflow `device-context-sync-v286.yml` kiểm tra:

1. restore;
2. build;
3. test;
4. version 2.8.6;
5. full memory sync bị tắt;

8. tạo distributed execution;
9. sync thiếu xác nhận bị chặn;
10. query chỉ chọn memory liên quan;
