# v2.8.9 — Ra lệnh sửa code từ điện thoại

Mục tiêu: cho Android gửi yêu cầu sửa code tới PersonalAI nhưng không biến Companion thành remote shell.

## Luồng

Android → AI Hub → desktop approval → PC/laptop có capability `git` + `build` → DevelopmentRun → Autonomous Developer pipeline → test/review/security/benchmark → experiment branch → PR → trạng thái trả về Android.

## Safety boundary

- Điện thoại chỉ gửi `Goal` và `RepositoryHint`.
- Điện thoại không gửi GitHub credential/token.
- Không cho remote shell trực tiếp.
- Không cho push trực tiếp main/master.
- Desktop approval là bắt buộc.
- Target phải là PC/laptop đang online.
- Target phải có capability `git` và `build` đang được phép.
- Experiment branch được tạo riêng cho từng command.
- Pipeline hiện có vẫn giữ test/review/security/benchmark/PR gates.
- Auto merge high-risk vẫn bị tắt.

## API Companion

- `GET /api/companion/client/development/commands`
- `POST /api/companion/client/development/commands`

## API desktop

- `GET /api/companion/admin/development/commands/status`
- `GET /api/companion/admin/development/commands`
- `POST /api/companion/admin/development/commands/{commandId}/execute`

## Android

Companion có thêm:

- ô mô tả thay đổi code;
- repository hint tùy chọn;
- nút gửi yêu cầu;
- danh sách trạng thái command;
- hiển thị PR number khi đã tạo.
