# v2.9.1 — Nhật ký toàn hệ thống

Mục tiêu của mốc này là nâng audit foundation thành system log tập trung, có thể truy vết một hành động xuyên suốt hệ thống bằng request/correlation ID.

## Dữ liệu log

Mỗi log giữ lại contract audit cũ và bổ sung:

- `level`: info, warning, error, security;
- `source`: module/nguồn phát sinh;
- `correlationId`: request/correlation identifier.

Các record audit cũ vẫn tương thích.

## HTTP request correlation

Mỗi API request đã có `X-PersonalAI-Request-Id`. v2.9.1 dùng cùng ID đó làm `correlationId` cho system log.

Request completion log chỉ ghi:

- HTTP method;
- path;
- status code;
- duration.

Không ghi:

- request body;
- Authorization header/token;
- query string;
- credential/secret payload.

Các endpoint đọc audit/system log không tự log chính truy vấn của chúng để tránh tạo noise/feedback loop.

## SQLite migration

Database `audit.db` hiện có được nâng cấp tại chỗ:

- thêm `level`;
- thêm `source`;
- thêm `correlation_id`;
- backfill level/source cho record cũ;
- thêm index cho level/source/correlation.

Không xóa hoặc rebuild dữ liệu audit cũ.

## API

API cũ vẫn giữ:

- `GET /api/audit`
- `GET /api/audit/summary`

API system log mới:

- `GET /api/system/logs/status`
- `GET /api/system/logs`
- `GET /api/system/logs/summary`

Có thể lọc system log theo:

- level;
- source;
- correlationId;
- agent;
- action;
- result.

## Giới hạn

Tiếp tục dùng giới hạn hiện có:

- retention: 90 ngày;
- tối đa 10.000 event;
- tối đa 200 record mỗi query.
