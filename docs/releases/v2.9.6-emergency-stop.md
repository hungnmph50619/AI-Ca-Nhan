# v2.9.6 — Nút dừng khẩn cấp

Mục tiêu của mốc này là cung cấp một emergency-stop toàn hệ thống có ưu tiên cao hơn các execution surface tự động.

## Global latch

Emergency stop có hai trạng thái:

- released;
- engaged.

Engage bắt buộc `ConfirmStop=true` và reason rõ ràng.
Release bắt buộc `ConfirmRelease=true` sau khi review.

Mỗi lần engage mới tăng `Generation` và phát một cancellation token đã bị cancel. Khi release, token source mới được tạo; token cũ vẫn giữ trạng thái cancelled cho công việc đã chạy trước đó.

## Tác động khi engage

- khóa ngay Desktop Control bằng `ComputerControlGate.Stop()`;
- chặn execution request mới bằng HTTP 423;
- cancel Tool execution đang chạy;
- cancel Agent execution đang chạy;
- interrupt Automation đang chạy và không lấy automation due mới;
- cancel Training đang chạy và không queue/run training mới;
- cancel Roadmap Autopilot đang chạy.

Các protected surfaces:

- agents;
- tools;
- browser;
- desktop;
- training/model-lab mutations;
- automation;
- development-autopilot.

## Audit không bị xóa

Emergency stop không xóa hoặc reset audit.

Engage/release ghi:

- `emergency-stop.engage`;
- `emergency-stop.release`;

với level `security`, source `emergency-stop`, correlation `emergency-stop:{generation}`.

Các endpoint đọc status/audit/system-log/action-explanation vẫn hoạt động khi stop đang engaged.

## Desktop

Phím dừng Windows cũ `Ctrl + Shift + F12` vẫn là local desktop safety control.

v2.9.6 bổ sung system-wide latch; engage system stop luôn gọi `ComputerControlGate.Stop()` để thu hồi desktop control session ngay.

## HTTP boundary

Khi engaged, mutation request trên execution surface bị chặn bằng:

- HTTP 423 Locked;
- message yêu cầu explicit release.

`POST /api/computer/control/stop` vẫn được phép.

## API

- `GET /api/system/emergency-stop/status`
- `POST /api/system/emergency-stop/engage`
- `POST /api/system/emergency-stop/release`

## Safety boundary

Emergency stop không tự release, không xóa checkpoint, không xóa log và không tự resume automation/training/agent sau release.
