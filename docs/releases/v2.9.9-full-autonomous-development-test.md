# v2.9.9 — Bài kiểm tra phát triển tự động toàn phần

Mục tiêu của mốc này là kiểm tra end-to-end chế độ phát triển hoàn toàn tự động trên nền toàn bộ safety plane v2.9.x trước khi tiến tới v3.0.

## Phạm vi test

Workflow `full-autonomous-development-test-v299.yml` chạy:

1. restore;
2. build;
3. unit tests;
4. khởi động PersonalAI trên workspace/repository test cô lập;
5. xác minh safety plane v2.9.x;
6. tạo low-risk improvement item;
7. tạo reproduction thật trong fixture;
8. tạo hypothesis + verified diagnosis;
9. tạo DevelopmentRun;
10. seed persisted evidence của những side effect bên ngoài đã hoàn tất;
11. kiểm tra autonomous emergency stop cho 0 transition;
12. resume;
13. chạy controller:
   - analysis;
   - coding;
   - testing;
   - review;
   - security;
   - benchmark;
   - push;
   - CI;
   - merge-policy;
   - local-sync;
   - completed;
14. xác minh report IDs được persist;
15. xác minh backlog item chuyển resolved;
16. xác minh system log và action explanation vẫn truy vết được;
17. xác minh safety plane vẫn healthy sau full run.

## Safety-plane preflight

Trước autonomous run, test bắt buộc xác minh:

- Unified Permissions:
  - default deny;
  - deny overrides allow;
  - workspace scoped;
  - explicit permission mutation confirmation.
- System Log:
  - request correlation;
  - không log request body;
  - không log Authorization header;
  - không log query string.
- Action Explanation:
  - audit grounded;
  - không AI-generated;
  - không exposed hidden reasoning;
  - không side effect.
- Undo:
  - explicit confirmation;
  - precondition revalidation;
  - workspace isolation;
  - invocation correlation;
  - audit trail.
- Resource Limits:
  - request rate;
  - concurrency;
  - request body size;
  - bounded rate-window memory;
  - fail-closed.
- Loop Guard:
  - duplicate fingerprint;
  - runaway cost;
  - branch/task guard;
  - audited stop reason;
  - fail-closed.
- Emergency Stop:
  - audit preserved;
  - explicit release required.
- Disaster Recovery:
  - archive integrity verification;
  - path traversal protection;
  - restore limits;
  - pre-restore backup;
  - rollback-on-failure;
  - explicit restore confirmation.
- Database Upgrade:
  - startup migration;
  - checksum validation;
  - atomic migration;
  - fail-closed;
  - current schema up-to-date.

## External side-effect boundary

CI không thực hiện GitHub push/PR/merge thật và không gọi external AI để tạo code.

Các stage external side-effect đã hoàn tất được seed bằng persisted evidence giống contract restart/no-replay của v2.7.12–v2.7.15. Controller phải reuse evidence này thay vì replay side effect.

Điều này kiểm tra:

- recovery/no-replay;
- state-machine transition;
- gate correlation;
- policy enforcement;
- completion persistence;

mà không tạo thay đổi bên ngoài ngoài ý muốn trong CI.

## Assertions bắt buộc

Autonomous result phải có:

- `Completed=true`;
- `PolicyBypassed=false`;
- đúng 10 transitions từ analysis đến completed;
- đủ từng action stage;
- emergency-stop path trả 0 transitions trước resume;
- DevelopmentRun giữ security/benchmark/GitHub/CI/merge/sync report IDs;
- improvement item chuyển `resolved`.

Sau run:

- system log phải có HTTP event cho autonomous invocation;
- action explanation phải grounded vào audit evidence;
- database migrations vẫn up-to-date;
- emergency stop phải released;
- loop guard vẫn fail-closed.

## Không được suy diễn quá mức

v2.9.9 chứng minh controller và safety architecture khép được **controlled low-risk success path** bằng persisted evidence cho external side effects.

Nó không khẳng định CI đã thực hiện push/merge GitHub thật hoặc external AI thật.
